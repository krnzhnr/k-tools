# 2.0.0

### Добавлено

1. Полный переход на C# / .NET 10, WinUI 3 (Windows App SDK) с поддержкой Fluent-дизайна Windows 11 и архитектурой MVVM.
2. Перенесены все инструменты медиаобработки на базе FFmpeg, QAAC, eac3to и mkvmerge: очистка метаданных, смена контейнера, конвертация субтитров (ASS/SSA/SRT ↔ WebVTT/SRT/ASS), кодирование аудио, изменение скорости аудио, разделение многоканального аудио на моно-дорожки, извлечение дорожек и встроенных шрифтов, сборка MKV с автопоиском сопутствующих дорожек, управление потоками и другие.
3. Новые скрипты: «Сдвиг аудио» (изменение задержки/опережения с сохранением в FLAC/WAV) и «Сдвиг субтитров» (корректировка тайминга SRT, ASS, SSA и VTT с поддержкой ввода в формате Aegisub).
4. Калькулятор сдвига таймингов с маскированным вводом времени в стиле Aegisub, расчетом разницы во времени, вставкой из буфера обмена и копированием результата.
5. Интерактивное дерево выбора дорожек с групповой фильтрацией, каскадным выделением и сортировкой вложений.
6. Drag-and-drop очередь файлов с автофильтрацией по расширениям, расчётом размера и отображением прогресса/ETA в реальном времени.
7. Менеджер зависимостей: автоматическое скачивание, распаковка и проверка внешних утилит (FFmpeg, eac3to, mkvmerge, DEE) с фоновой установкой.
8. Автообновление приложения: проверка, скачивание и тихая установка новых версий, включая пререлизы.
9. Встроенная система переименования выходных файлов (PowerRename-style): regex и текстовый поиск/замена, автонумерация, переменные даты/времени/UUID, пользовательские шаблоны с сохранением в JSON и живым предпросмотром.
10. Отдельное окно предпросмотра субтитров с фильтрацией по актёрам, стилям и эффектам, поиском по имени, ручным включением/отключением реплик, подсветкой тегов и CAPS-реплик.
11. Интерактивная фильтрация текста по регулярным выражениям (Regex) в конвертере субтитров с последовательной обработкой по шагам и настройкой режима очистки.
12. Настройки видеокодирования: целевой битрейт x265 (ABR) с авторасчётом мин/макс битрейта и буфера, режим Lossless, визуальный редактор ключевых слов для аудио и субтитров.
13. Раздел общих настроек: тема оформления, фон (Mica/Acrylic), правила перезаписи, пути экспорта, логирование.
14. Отображение FPS и битрейта в реальном времени в строке состояния при выполнении медиаобработки через FFmpeg.
15. Интеграция с контекстным меню Проводника Windows («Открыть в K-Tools») с выбором скрипта и передачей файлов в единое окно (Single-Instance).
16. Гибкое позиционирование новых дорожек перед встроенными в скрипте сборки MKV с автоматическим расчётом порядка.
17. Современные иконки скриптов на основе шрифта Segoe Fluent Icons (скругленные, в стиле Windows 11).
18. Интеграция внешней зависимости yt-dlp nightly с возможностью автоматической ежедневной проверки обновлений через GitHub API.
19. Поддержка портативного Node.js с автоматической распаковкой zip-архивов и очисткой вложенной корневой директории для удобного вызова исполняемого файла.
20. Расширение функционала DependencyManager для поддержки прямых ссылок на загрузку и скачивания чистых исполняемых файлов без архивации.
21. Новый скрипт «Загрузка медиа» в категории «Сеть» для скачивания видео и аудио по ссылкам через yt-dlp с динамическим получением доступных разрешений и битрейтов с источника, а также возможностью скачивания ручных и автоматических субтитров.
22. Добавлена опция «Встраивать субтитры в видео (контейнер MKV)» для автоматического слияния видеоряда и выбранной дорожки субтитров с помощью FFmpeg непосредственно в процессе загрузки.
23. Исправлено потенциальное зависание (deadlock) при фоновом извлечении метаданных через yt-dlp путем оптимизации перенаправления потоков ввода-вывода (stderr).
24. Исправлена ошибка разбора FPS в виде вещественных чисел из JSON-вывода, предотвращающая падение парсера.
25. Вывод логов в реальном времени при скачивании медиафайлов.
26. Учет глобальной настройки перезаписи файлов в yt-dlp с использованием аргументов `--force-overwrites`/`--no-force-overwrites`.
27. Автоматическая очистка и форматирование скачанных субтитров формата WebVTT от лишнего мусора, тегов пословесной подсветки и настроек позиционирования.
28. Глобальный механизм проверки ошибок выполнения скриптов по префиксу `❌` для установки статуса «Ошибка» и сброса прогресса для сбойных файлов в очереди.
29. Новая иконка глобуса (Segoe Fluent Icons) и уникальные цвета для категорий «Сеть» (коралловый) и «Инструменты» (янтарный) на домашней странице и странице зависимостей.
30. Устранено ошибочное появление чекбокса «Только часть» для параметров удаления тегов оформления субтитров в скрипте кодирования видео.
31. Реализована поддержка глобальной настройки автосоздания подпапки результатов в скриптах очистки метаданных и извлечения дорожек.
32. Оптимизирована производительность логов скачивания медиафайлов благодаря дросселированию обновления интерфейса и ограничению размера буфера логов.
33. Добавлена автоматическая прокрутка журнала выполнения скриптов до самого низа при добавлении новых строк и при раскрытии журнала.
34. Реализовано гарантированное принудительное завершение всех дочерних CLI-процессов (включая ffmpeg и yt-dlp) при закрытии главного окна приложения.
35. Добавлено динамическое отображение пути сохранения по умолчанию в плейсхолдере строки выходного пути с поддержкой автосоздаваемых подпапок.
36. Отключено автоматическое подчеркивание пути проверки орфографии в поле выходного каталога.
37. Обеспечено сохранение и восстановление выбранного выходного пути индивидуально для каждого скрипта при переключении между ними.
38. Устранено зависание UI-потока при добавлении сетевых ссылок (URL) в список за счет блокировки вызова FileInfo для сетевых путей.
39. Устранено ошибочное добавление битрейт-параметров видео во все остальные скрипты за счет ограничения вызова обработчиков авторасчета битрейта только для скрипта кодирования видео.
40. Исправлена синхронизация регулярных выражений text_patterns при открытии окна предпросмотра субтитров, гарантируя загрузку сохраненных шаблонов.
41. Добавлена автоматическая нормализация и очистка устаревших/некорректных ключей параметров внутри секций скриптов при запуске приложения.

4. Исправлен парсинг прогресса и скорости кодирования QAAC при наличии дробной части в секундах.

# 1.5.0

### Добавлено

1. Поддержка аудио-контейнеров `.mka` в общем списке форматов и в модуле демуксинга.
2. Добавлена система управления временными файлами (`TempFileManager`): реализовано автоматическое отслеживание и очистка данных как при штатном выходе, так и при следующем запуске.
3. Добавлена функциональность прерывания работы скриптов: основная кнопка запуска теперь работает как переключатель (Выполнить/Остановить), позволяя безопасно останавливать активные дочерние процессы и автоматически удалять неполные выходные файлы.
4. Добавлены опции удаления исходного файла после обработки и прямой подмены оригинала (переименование результата в имя исходного файла) для модулей управления и замены потоков.
5. Добавлена поддержка навигации с помощью боковых кнопок мыши (кнопка «Назад») для возврата к предыдущим разделам интерфейса.
6. Автоматическая конвертация субтитров формата Timed Text и WebVTT в ASS при демуксинге.
7. Обогащение заголовков дорожек через pymediainfo при отсутствии данных от mkvmerge.
8. Различение дорожек с одинаковым языком: к субтитрам в дереве добавляется заголовок дорожки для уникальности.

### Исправлено

1. Устранено «состояние гонки» при массовой параллельной обработке: исправлены ошибки в менеджере настроек и подсистеме создания папок, из-за которых файлы могли сохраняться в некорректную директорию.
2. Исправлена логика исключения и замены дорожек: обеспечено корректное использование специфичных флагов `mkvmerge` для каждого типа потока и предотвращена «утечка» глав и тегов из исходных файлов.
3. Исправлены ошибки первого запуска `deew` и ошибки доступа при работе с путями, содержащими кириллицу.
4. Исправлен алгоритм замены потоков в контейнерах MKV: заменяемые дорожки сохраняют свою оригинальную позицию в файле и полностью наследуют все метаданные (язык, имя, флаги доступности и приоритета).
5. Исправлен выход элементов интерфейса за пределы окна при использовании очень длинных имен файлов и путей: реализовано их автоматическое сокращение в статус-баре и списках замен.
6. Исправлено зависание спиннера на вкладке «Дорожки» при сбое фонового технического анализа файлов (например, при отсутствии kt-ffprobe.exe или повреждении контейнера).


### Изменено

1. Оптимизировано отображение названия приложения в таскбаре Windows: удален информационный суффикс, теперь при наведении на иконку отображается только «K-Tools».
2. Оптимизирована архитектура приложения: внедрён паттерн проектирования Singleton для менеджера настроек и всех инфраструктурных раннеров (FFmpeg, FFProbe, mkvmerge и др.). Это устраняет их многократную инициализацию и решает проблему избыточных сообщений в логе.
3. Улучшена диагностика ошибок: теперь захватывается полный вывод `mkvmerge` (stdout и stderr) при сбоях.
4. Реализована автоматическая установка флагов «по умолчанию» и «принудительно» для всех дорожек, добавляемых через модуль муксинга из внешних файлов для их приоритетного выбора в плеерах.
5. Полностью переработан «Безопасный режим» для `deew`: теперь временные копии исходных файлов не создаются, что экономит место на диске и исправляет ошибки определения длительности потока.
6. Улучшена система защиты файлов: реализовано автоматическое разрешение конфликтов имен (добавление суффиксов `_1`, `_2`) и блокировка записи в файлы, занятые другими процессами.
7. Расширена поддержка кодека ALAC: реализовано сохранение в контейнер CAF (расширение `.alac`) для обеспечения совместимости с FFmpeg и внешними плеерами.
8. Интерфейс транскодирования теперь динамически скрывает несовместимые опции (например, упаковку в M4A для форматов, отличных от QAAC/AAC/ALAC).
9. Унифицирована обработка имен файлов (Path.stem) во всех модулях приложения для повышения стабильности сопоставления.
10. Улучшен интерфейс модуля демуксинга: реализована полноценная поддержка родительских чекбоксов для файлов, позволяющая массово выделять или снимать выбор со всех дорожек файла одним кликом.
11. Устранено замусоривание рабочих директорий лог-файлами eac3to: реализована автоматическая очистка файлов журнала (log*.txt) после завершения работы утилиты.
12. Категория «Муксинг» переименована в «Контейнеры» для упрощения навигации и соответствия общему стилю интерфейса.
13. Уменьшена длительность анимаций перехода между вкладками скриптов.
