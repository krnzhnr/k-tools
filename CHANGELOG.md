# 1.7.0

### Добавлено

1. Инструмент «Видео-процессор»: программное/аппаратное кодирование, вшивание субтитров, извлечение шрифтов, удаление строк по фильтру, 10-битный цвет.
2. Фильтрация ASS → VTT: по полю «Эффект», КАПСу, поддержка SRT и ручное исключение строк в предпросмотре.
3. Автоматический апмикс каналов (3.0, 4.0 и др.) для совместимости с кодировщиком Dolby.
4. Предупреждение о настройках, способных нарушить отображение длительности аудио.
5. Поддержка форматов `.m2ts`, `.ts` и аудио-сегментов `.m4s` (DASH).
6. Всплывающие подсказки ко всем ключевым параметрам настроек.
7. Расчет битрейта, скорости и времени завершения (ETA) при обработке видео.
8. Интерактивная вкладка «Логи» для мониторинга работы в реальном времени.
9. Выбор разрядности (16/24/32-bit/32-bit Float) при экспорте в WAV.
10. Ручной выбор директории сохранения логов при отсутствии прав доступа.
11. Приоритет языков во вкладке «Аудио» для автоматического выбора лучшего потока.
12. Валидация добавляемых языковых кодов по стандартам ISO (2 и 3 буквы).
13. Встроенное обновление с GitHub: ручная/автоматическая проверка, выбор между стабильными версиями и пре-релизами.
14. Кнопка быстрого скачивания обновления в настройках и всплывающая подсказка при обнаружении новой версии.
15. Система отложенной динамической загрузки внешних бинарных зависимостей (FFmpeg, Dolby Encoding Engine, MKVToolNix, eac3to) непосредственно внутри приложения.
16. Интерактивный экран управления зависимостями с отображением карточек компонентов, статусов, прогресса скачивания, скорости загрузки и кнопок действий.
17. Автоматическое перенаправление на экран установки зависимостей при первом запуске приложения при обнаружении их отсутствия.
18. Визуальная деактивация недоступных скриптов на главном экране и в боковом меню навигации с выводом информационных предупреждений о недостающих компонентах.
19. Информационные баннеры на страницах скриптов с предложением быстрой установки недостающих компонентов при попытке их открытия.

### Изменено

1. Автоматическая упаковка AAC, QAAC, ALAC в M4A для корректного отображения длительности.
2. Ускорен запуск приложения и работа предпросмотра субтитров.
3. Прямой запрос к драйверу GPU для точной проверки поддержки NVENC, CUVID и AV1.
4. Оптимизация фильтров демуксинга для предотвращения конфликтов правил.
5. Автопереключение на папку профиля пользователя при отсутствии прав записи в директорию программы.
6. Цветовые индикаторы статуса файлов: спиннеры при обработке, галочки при успехе, крестики при ошибках.
7. Улучшена читаемость статус-бара благодаря исключению длинных имен файлов.
8. Двухвкладочная компоновка страниц («Файлы» и «Настройки») для всех скриптов.
9. Поддержка анимированных картинок при ремуксинге и автопроверка совместимости кодеков с рекомендацией кодирования.
10. Отображение версии приложения перенесено в блок проверки обновлений.
11. Упрощена структура файла конфигурации с автоматическим переносом старых настроек.
12. Фоновый анализ дорожек без блокировки интерфейса.
13. Оптимизация обновления списков файлов для повышения плавности.
14. Снижение частоты логирования при изменении геометрии окна.
15. Переход на компиляцию через Nuitka: нативный код, быстрый запуск, защита от ложных срабатываний антивирусов.
16. Минимизирована задержка переключения разделов за счет быстрой анимации переходов.
17. Увеличен шаг скролла для устранения инпут-лага прокрутки списков.
18. Автоматическое пересоздание тестового релиза с нуля для предотвращения дублирования файлов.
19. Оптимизирован размер установщика приложения (сокращен с ~400 МБ до ~50 МБ) за счет исключения внешних бинарных утилит из базовой сборки.
20. Система сборки адаптирована для раздельного создания базового дистрибутива и полной автономной версии с помощью специального флага.
21. Изменено визуальное представление карточек зависимостей: интерфейс переведен на прямоугольные вертикальные карточки с центрированными иконками и кнопками действий со встроенными индикаторами состояния.

### Исправлено

1. Ложные срабатывания очистки субтитров (кавычки, короткие реплики) и лишние пустые строки в VTT.
2. Шипение в конце файлов при кодировании через QAAC и сбои декодирования PCM в M2TS.
3. Параметры eac3to для режима (24.000 → 23.976): добавлено явное указание частоты `-24.000`.
4. Сбои записи настроек и открытия папки логов в защищенных директориях Windows.
5. Зависание кнопки управления и обработка очереди при отмене задачи «Муксинг».
6. Визуальное наложение и конфликты аргументов CRF и битрейта для x265.
7. Неверная пометка завершившихся ошибкой файлов как успешных.
8. Сброс статусов очереди при отмене обработки файлов.
9. Скрытие полей качества при активации режима Lossless для NVENC.
10. Верстка полей выбора формата и параметров в аудио-конвертере.
11. Статус предупреждения (оранжевый значок) вместо зеленой галочки для пропущенных файлов.
12. Сброс битрейта и параметров кодирования видео после перезапуска или смены режима Lossless.
13. Отрисовка прогресс-баров и статусов файлов в демуксинге.
14. Черный цвет имен файлов в темной теме на Windows 10.
15. Сохранение даты последней проверки обновлений при автозапуске.
16. Логирование удаления старых установщиков (перевод из stdout в подсистему логов).
17. Выход текста уведомления о новой версии за границы всплывающего окна.
18. Фатальный сбой (Segfault) при переходе к страницам из свернутого бокового меню.
19. Залипание выделения кнопок бокового меню при переходах (включая мышь и клавиатуру).
20. Блокировка переходов назад боковой кнопкой мыши при фокусе в списках и таблицах.
21. Ошибка верификации внешних компонентов после их скачивания, приводившая к ложному сообщению об отсутствии распакованных исполняемых файлов.

# 1.6.0

### Добавлено

1.  Поддержка аудиоформата `.ec3` (E-AC3) в интерфейсе и при обработке потоков.
2.  Опция «Создавать отдельную подпапку для каждого файла» в модуле демуксинга для автоматической группировки извлеченных дорожек.
3.  Новая категория «Субтитры» в навигации приложения.
4.  Скрипт «ASS → VTT» для конвертации субтитров ASS/SSA в формат WebVTT с фильтрацией строк по актёрам и стилям (вкладки с динамическими списками чекбоксов), удалением тегов форматирования и пропуском пустых строк.
5. Многоступенчатая очистка субтитров: интеграция фильтров k-tools с финальной обработкой через FFmpeg для идеально валидных VTT.
6. Автоматическая сортировка реплик по времени и нормализация таймкодов.
7. Визуальный предпросмотр очистки: красная подсветка для ручных фильтров и фиолетовая для автоматики FFmpeg.
8. Настройка «Удалять теги форматирования» теперь выключена по умолчанию (рекомендуется режим FFmpeg).
9. Возможность ручного исключения каждой отдельной строки субтитров через чекбоксы в режиме предпросмотра.
10. Кнопка «Развернуть» для открытия панели настроек и предпросмотра в отдельном полноэкранном окне для удобной работы с длинными списками.
11. Отображение всех строк субтитров в предпросмотре (включая не затронутые фильтрами) для полного контроля над финальным файлом.

### Изменено

1. Нижняя панель управления (выбор пути и кнопка запуска) зафиксирована. Прогресс-бар теперь компактно размещен в верхней части этой панели.
2. Визуальное оформление нижней панели приведено улучшено: увеличен нижний отступ до 16px, кнопка «Обзор» сделана неакцентной.

### Исправлено

1. Исправлена логика группировки файлов в модуле «Муксинг»: устранена ошибка, из-за которой аудио-контейнеры (например, `.mka`) ошибочно принимались за видео-файлы, что препятствовало корректной замене оригинальных дорожек.
2. Исправлен ложный отчёт об успехе при даунмиксе: теперь после завершения работы DEE проверяется фактическое создание выходного файла на диске.

# 1.5.0

### Добавлено

1. Поддержка аудио-контейнеров `.mka` в общем списке форматов и в модуле демуксинга.
2. Добавлена система управления временными файлами (`TempFileManager`): реализовано автоматическое отслеживание и очистка данных как при штатном выходе, так и при следующем запуске.
3. Добавлена функциональность прерывания работы скриптов: основная кнопка запуска теперь работает как переключатель (Выполнить/Остановить), позволяя безопасно останавливать активные дочерние процессы и автоматически удалять неполные выходные файлы.
4. Добавлены опции удаления исходного файла после обработки и прямой подмены оригинала (переименование результата в имя исходного файла) для модулей управления и замены потоков.
5. Добавлена поддержка навигации с помощью боковых кнопок мыши (кнопка «Назад») для возврата к предыдущим разделам интерфейса.
6. Автоматическая конвертация субтитров формата Timed Text и WebVTT в ASS при демуксинге.
7. Обогащение заголовков дорожек через pymediainfo при отсутствии данных от mkvmerge.
8. Различение дорожек с одинаковым языком: к субтитрам в дереве добавляется заголовок дорожки для уникальности.

### Исправлено

1. Устранено «состояние гонки» при массовой параллельной обработке: исправлены ошибки в менеджере настроек и подсистеме создания папок, из-за которых файлы могли сохраняться в некорректную директорию.
2. Исправлена логика исключения и замены дорожек: обеспечено корректное использование специфичных флагов `mkvmerge` для каждого типа потока и предотвращена «утечка» глав и тегов из исходных файлов.
3. Исправлены ошибки первого запуска `deew` и ошибки доступа при работе с путями, содержащими кириллицу.
4. Исправлен алгоритм замены потоков в контейнерах MKV: заменяемые дорожки сохраняют свою оригинальную позицию в файле и полностью наследуют все метаданные (язык, имя, флаги доступности и приоритета).
5. Исправлен выход элементов интерфейса за пределы окна при использовании очень длинных имен файлов и путей: реализовано их автоматическое сокращение в статус-баре и списках замен.

### Изменено

1. Оптимизировано отображение названия приложения в таскбаре Windows: удален информационный суффикс, теперь при наведении на иконку отображается только «K-Tools».
2. Оптимизирована архитектура приложения: внедрён паттерн проектирования Singleton для менеджера настроек и всех инфраструктурных раннеров (FFmpeg, FFProbe, mkvmerge и др.). Это устраняет их многократную инициализацию и решает проблему избыточных сообщений в логе.
3. Улучшена диагностика ошибок: теперь захватывается полный вывод `mkvmerge` (stdout и stderr) при сбоях.
4. Реализована автоматическая установка флагов «по умолчанию» и «принудительно» для всех дорожек, добавляемых через модуль муксинга из внешних файлов для их приоритетного выбора в плеерах.
5. Полностью переработан «Безопасный режим» для `deew`: теперь временные копии исходных файлов не создаются, что экономит место на диске и исправляет ошибки определения длительности потока.
6. Улучшена система защиты файлов: реализовано автоматическое разрешение конфликтов имен (добавление суффиксов `_1`, `_2`) и блокировка записи в файлы, занятые другими процессами.
7. Расширена поддержка кодека ALAC: реализовано сохранение в контейнер CAF (расширение `.alac`) для обеспечения совместимости с FFmpeg и внешними плеерами.
8. Интерфейс транскодирования теперь динамически скрывает несовместимые опции (например, упаковку в M4A для форматов, отличных от QAAC/AAC/ALAC).
9. Унифицирована обработка имен файлов (Path.stem) во всех модулях приложения для повышения стабильности сопоставления.
10. Улучшен интерфейс модуля демуксинга: реализована полноценная поддержка родительских чекбоксов для файлов, позволяющая массово выделять или снимать выбор со всех дорожек файла одним кликом.
11. Устранено замусоривание рабочих директорий лог-файлами eac3to: реализована автоматическая очистка файлов журнала (log*.txt) после завершения работы утилиты.
12. Категория «Муксинг» переименована в «Контейнеры» для упрощения навигации и соответствия общему стилю интерфейса.
13. Уменьшена длительность анимаций перехода между вкладками скриптов.
