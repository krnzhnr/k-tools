# 2.0.0-csharp-dev

### Добавлено

1. Перенос приложения на современную платформу C#, .NET 8 и WinUI 3 (Windows App SDK) с полной поддержкой Fluent-интерфейса Windows 11.
2. Интеграция 9 полноценных инструментов медиаобработки на базе FFmpeg, QAAC, eac3to и mkvmerge:
   - **Очистка метаданных** (с функцией фоллбэка на симуляцию при отсутствии FFmpeg);
   - **Смена контейнера** (с автоматическим анализом совместимости кодеков без перекодирования);
   - **Конвертация субтитров** (поддержка ASS/SSA/SRT с экспортом в WebVTT/SRT/ASS и чисткой CAPS-реплик);
   - **Кодирование аудио** (QAAC, AAC, MP3, FLAC, WAV и др. с выбором разрядности и битрейта);
   - **Изменение скорости аудио** (пресеты PAL ↔ NTSC через eac3to);
   - **Разделение каналов** (многоканальное аудио в моно-WAV с автоматической склейкой в стереопары);
   - **Извлечение дорожек** (One-Pass извлечение выбранных аудио/видео/субтитров и встроенных шрифтов);
   - **Сборка MKV** (автоматический поиск сопутствующих дорожек и субтитров по базовому имени с табличной группировкой);
   - **Управление потоками** (удаление нежелательных дорожек или сохранение выбранных в MKV/MP4 контейнерах).
3. Интерактивное дерево выбора дорожек с поддержкой групповой фильтрации, каскадного выделения и сортировки вложений.
4. Drag-and-Drop queue файлов с автофильтрацией по расширениям, расчетом размера и индикацией прогресса.
5. Декларативная система параметров скриптов с динамической генерацией Fluent-виджетов настроек и автосохранением.
6. Встроенная подсистема фонового управления зависимостями: автоматическое скачивание, распаковка и верификация внешних утилит (FFmpeg, eac3to, mkvmerge, DEE).
7. Раздел общих настроек программы (управление темной/светлой темой, правилами перезаписи, путями экспорта и логированием).
8. Автоматизированный CI/CD воркфлоу в GitHub Actions для сборки C#-версии и мгновенной публикации пререлиза.
9. Выбор эффекта оформления фона окон приложения (Mica или Acrylic) в настройках персонализации.
10. Построчный парсинг прогресса и скорости кодирования QAAC на основе stderr.
11. Динамическая видимость настроек скриптов по условиям VisibleIfKey и VisibleIfValues.
12. Построчный парсинг прогресса выполнения утилиты eac3to в скрипте изменения скорости аудио.
13. Интеграция фоновой установки eac3to Decoder Pack в Inno Setup инсталлятор с возможностью выбора при установке.
14. Поддержка новой внешней зависимости «Декодеры eac3to» в менеджер зависимостей с автоматической проверкой установленного DirectShow-фильтра NeAudio2.ax и возможностью тихой установки с запросом UAC.
15. Реализация корректного и безопасного удаления декодеров eac3to из системы: приоритетный запуск оригинального деинсталлятора, а в качестве резервного сценария — выполнение временного пакетного скрипта с chcp 65001 и правами администратора для полной разрегистрации DirectShow-фильтров, очистки ключей реестра и специфических файлов без удаления общих системных библиотек Visual C++ Runtime.
16. Полноценная C# реализация скрипта «Сборка MKV» с автоматическим поиском сопутствующих аудиодорожек и файлов субтитров по имени в каталоге источника.
17. Уникальное табличное представление для скрипта «Сборка MKV» с автоматическим группированием видео, аудио и субтитров в единые строки на основе базового имени файла.
18. Полноценная C# реализация скрипта «Управление потоками» с поддержкой удаления нежелательных дорожек или сохранения только выбранных.
19. Интеграция автоматической фоновой и ручной проверки наличия обновлений, их скачивания и тихой установки с запуском инсталлятора из интерфейса программы.
20. Разработка изолированного и протестированного SemVer-компаратора для точного сопоставления стабильных версий и preview-сборок.
21. Архитектурная поддержка сложных многокритериальных условий видимости полей настроек в пользовательском интерфейсе с логическим И.
22. Добавление настроек целевого битрейта x265 (ABR) на вкладку параметров кодирования видео.
23. Возвращение информационной заглушки видеофильтров на панель параметров кодирования видео.

25. Интерактивная логика для режима Lossless кодирования видео с блокировкой пресета и автоматическим переключением в p1.
26. Динамический авторасчет минимального/максимального битрейтов и размера буфера в реальном времени при изменении целевого битрейта.
27. Поддержка любых медиаконтейнеров, включая аудиоконтейнеры (такие как `.mka` и `.m4a`), в инструменте «Разборка контейнера» с корректным сбором и отображением количества аудиоканалов через ffprobe.
28. Интегрировано плавное, монотонно возрастающее отслеживание прогресса в процентах в реальном времени при даунмиксе аудио через Dolby Encoding Engine (DEE) с разделением фаз измерения громкости и кодирования.
29. Реализовано отслеживание и отображение прогресса сборки MKV-файлов в реальном времени в процентах при вызовах mkvmerge.
30. Функция интерактивного предпросмотра субтитров с боковым меню фильтрации в отдельном окне WinUI 3.

33. Возможность фильтрации и разграничения строк субтитров по конкретным файлам в окне предпросмотра с помощью раскрывающегося меню в боковой панели.

### Изменено

1. Интерфейс полностью адаптирован под стиль Windows 11: внедрен NavigationView для бокового меню, закреплены шапка и нижняя панель управления, оптимизированы отступы и размеры элементов управления.
2. Рабочая панель запуска скриптов разделена на вкладки «Файлы» и «Настройки» для удобства навигации.
3. Оптимизирован список очереди файлов: используется ListView с кольцевой индикацией прогресса и статусов, очередь остается интерактивной во время выполнения скриптов.
4. Архитектура приложения переведена на паттерн MVVM для повышения надежности, разделения логики и обеспечения совместимости с Native AOT.
5. Настройки программы теперь сериализуются в JSON с поддержкой кириллицы (UTF-8).
6. Файл установщика (.exe) генерируется через Inno Setup сжатием LZMA2, при этом в имени файла больше не используется временная метка (дата и время сборки).
7. Обновлено отображение зависимостей: размер на диске теперь указывает размер после распаковки (с указанием объема скачивания), а для длинных текстов статусов добавлена бегущая строка при наведении.
8. Отображение кольцевого прогресс-бара (ProgressRing) в списке файлов при обработке и переход на строго типизированные состояния обработки.
9. Объединение кнопок «Выполнить» и «Отменить» в единую динамическую кнопку-переключатель запуска скриптов.
10. Перенос адаптивного расчета общего прогресса очереди, прогнозирования ETA и форматирования статуса из Python-версии.
11. Увеличение частоты вывода прогресса FFmpeg до 100 мс для более плавной анимации индикаторов.
12. Адаптивная видимость параметров кодирования аудио в зависимости от выбранного целевого формата.
13. Автоматическое скрытие пустых карточек параметров в настройках скриптов при скрытии дочерних полей.
14. Предупреждение при попытке отключить упаковку в M4A с сокращением ее описания.
15. Оптимизация отступов (Margins/Spacing) на вкладке параметров скриптов для повышения компактности UI.
16. Вертикальное центрирование текстовых меток параметров относительно соответствующих полей ввода.
17. Кардинальная оптимизация и ускорение вкладки логов: переход на виртуализированный список вывода событий с прозрачным фоном для поддержки эффектов Acrylic и Mica, автоматическим открытием в конце списка и лимитированием размера очереди отображения.
18. Реструктуризация файлов репозитория: исходные коды C#-версии перенесены в корень, а Python-исходники сгруппированы во внутренней подпапке.
19. Активация запуска скриптов «Сборка MKV» и «Управление потоками» с главного экрана приложения.
20. Оптимизация верстки и редизайн таблицы сборки MKV для повышения компактности и удобства управления.
21. Настройка автоматического воркфлоу сборки превью-версий в GitHub Actions при пуше в ветку разработки (develop) с динамическим версионированием на основе номера запуска.
22. Добавление элементов ручной проверки обновлений, статусной плашки с примечаниями к выпуску и прогресс-бара скачивания с процентами в настройки приложения.
23. Установлена дефолтная версия 2.0.0 в файле проекта KTools.App.csproj для корректного отображения версии при отладке в Visual Studio.
24. Изменен внешний вид кнопок пошагового изменения значений в полях ввода чисел на встроенный режим (Inline) для более удобного и наглядного управления битрейтом и буфером.
25. Добавлен автоматический сброс фокуса (и, соответственно, сохранение текста) при клике на пустую область окна или нажатии клавиши Enter в текстовых и числовых полях ввода параметров.
26. Оптимизирована верстка строк редактора ключевых слов (KeywordList): первая колонка для галочки получила фиксированную ширину 32 пикселя с удалением внутренних отступов, а кнопка удаления и текстовое поле выровнены по высоте (32 пикселя), что устранило пустое пространство и диспропорции.
27. Добавлен горизонтальный сепаратор (разделительная линия) под главными вкладками «Файлы» и «Настройки» на рабочей панели скрипта с боковыми отступами в 5 пикселей и увеличенными вдвое (до 16 пикселей) верхним и нижним отступами для улучшения визуальной структуры.
28. Сокращены внешние и встроенные верхние отступы у вложенного блока вкладок параметров скрипта (Видео, Аудио, Субтитры), что позволило расположить его более компактно и ближе к горизонтальному разделителю.
29. Убран русскоязычный термин «Долби» в сообщениях логов, заменен на официальное наименование «Dolby».
30. Сокращены наименования выходных аудиоформатов в настройках скрипта «Даунмикс в Stereo» до компактного вида (E-AC3, AC3, AAC, FLAC).
31. Реализовано скрытие настройки битрейта в параметрах скрипта «Даунмикс в Stereo» при выборе формата без потерь (FLAC).
32. Фильтры субтитров перенесены из рабочей панели в боковое меню NavigationView окна предпросмотра с сокращением его ширины в два раза для оптимизации рабочей области, а глобальные чекбоксы вынесены в шапку предпросмотра для повышения интерактивности интерфейса.
33. Размер по умолчанию для окна предпросмотра субтитров изменен на 1600x1000 (соотношение 16:10, среднее между 720p и 1080p с увеличенной высотой) с автоматическим центрированием относительно рабочей области экрана.
34. Списки актёров, стилей и эффектов в окне предпросмотра переведены на многоколоночную адаптивную сетку с автоматическим распределением элементов по горизонтали для эффективного использования экранного пространства.
35. Настроен деинсталлятор программы для полной и корректной очистки динамически загруженных бинарных зависимостей (папки bin) при удалении приложения с компьютера.
