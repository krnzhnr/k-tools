# 2.0.0-csharp-dev

### Добавлено

1. Перенос приложения на современную платформу C#, .NET 8 и WinUI 3 (Windows App SDK) с полной поддержкой Fluent-интерфейса Windows 11.
2. Интеграция 7 полноценных инструментов медиаобработки на базе FFmpeg, QAAC и eac3to:
   - **Очистка метаданных** (с функцией фоллбэка на симуляцию при отсутствии FFmpeg);
   - **Смена контейнера** (с автоматическим анализом совместимости кодеков без перекодирования);
   - **Конвертация субтитров** (поддержка ASS/SSA/SRT с экспортом в WebVTT/SRT/ASS и чисткой CAPS-реплик);
   - **Кодирование аудио** (QAAC, AAC, MP3, FLAC, WAV и др. с выбором разрядности и битрейта);
   - **Изменение скорости аудио** (пресеты PAL ↔ NTSC через eac3to);
   - **Разделение каналов** (многоканальное аудио в моно-WAV с автоматической склейкой в стереопары);
   - **Извлечение дорожек** (One-Pass извлечение выбранных аудио/видео/субтитров и встроенных шрифтов).
3. Интерактивное дерево выбора дорожек с поддержкой групповой фильтрации, каскадного выделения и сортировки вложений.
4. Drag-and-Drop очередь файлов с автофильтрацией по расширениям, расчетом размера и индикацией прогресса.
5. Декларативная система параметров скриптов с динамической генерацией Fluent-виджетов настроек и автосохранением.
6. Встроенная подсистема фонового управления зависимостями: автоматическое скачивание, распаковка и верификация внешних утилит (FFmpeg, eac3to, mkvmerge, DEE).
7. Раздел общих настроек программы (управление темной/светлой темой, правилами перезаписи, путями экспорта и логированием).
8. Автоматизированный CI/CD воркфлоу в GitHub Actions для сборки C#-версии и мгновенной публикации пререлиза.
9. Выбор эффекта оформления фона окон приложения (Mica или Acrylic) в настройках персонализации.

### Изменено

1. Интерфейс полностью адаптирован под стиль Windows 11: внедрен NavigationView для бокового меню, закреплены шапка и нижняя панель управления, оптимизированы отступы и размеры элементов управления.
2. Рабочая панель запуска скриптов разделена на вкладки «Файлы» и «Настройки» для удобства навигации.
3. Оптимизирован список очереди файлов: используется ListView с кольцевой индикацией прогресса и статусов, очередь остается интерактивной во время выполнения скриптов.
4. Архитектура приложения переведена на паттерн MVVM для повышения надежности, разделения логики и обеспечения совместимости с Native AOT.
5. Настройки программы теперь сериализуются в JSON с поддержкой кириллицы (UTF-8).
6. Файл установщика (.exe) генерируется через Inno Setup сжатием LZMA2, а в имя файла добавляется дата и время сборки.

### Исправлено

1. Исправлена критическая ошибка приведения типов JSON при чтении сохраненных параметров.
2. Устранен сброс очереди файлов, лога событий и глобального прогресса при переходах между страницами приложения.
3. Исправлено некорректное отображение кириллицы (кракозябр) в элементах дерева дорожек и логах CLI-утилит.
4. Исправлены ошибки в конвейерах обработки дорожек: учтен выбор только определенных дорожек пользователя, исправлены индексы при извлечении встроенных шрифтов в MKV.
5. Устранены зависания фонового процесса `KTools.App.exe` после закрытия главного окна приложения.
6. Исправлены сбои в работе Apple AAC кодировщика (QAAC) в песочнице AppContainer путем запуска во временном каталоге.
7. Решены проблемы с каскадным поведением чекбоксов и сбросом выделения дорожек в дереве при переключении фильтров.
8. Исправлена ошибка Dolby-кодирования через DEE, связанная с переносом временных файлов.
9. Исправлена ошибка сборки приложения в CI/CD, связанная с отсутствием файла манифеста в репозитории.

5. Повышение информативности: вкладка «Логи» для мониторинга в реальном времени с возможностью смены папки сохранения журналов в настройках.
6. Модуль обновлений и зависимостей: автоматическое/ручное обновление с GitHub (включая пре-релизы) со всплывающими оповещениями, а также система отложенной динамической загрузки внешних бинарных утилит (FFmpeg, Dolby, MKVToolNix, eac3to) с карточками статусов, автопереходом при первом старте и баннерами быстрой установки.

3. Системные улучшения: автоматический перенос старых файлов конфигурации пользователей, автопереключение на папку профиля пользователя при нехватке прав записи и перенос отображения версии программы в блок обновлений.
4. Оптимизация сборки и дистрибуции: переход на компиляцию через Nuitka (сокращение веса установщика с ~400 до ~50 МБ, раздельная сборка), автоматическое пересоздание тестовых релизов на GitHub и обновление экрана зависимостей с переходом на высокоэффективное сжатие LZMA2 (`.tar.xz`).
