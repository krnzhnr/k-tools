# 2.0.0

### Добавлено

1. Полный перенос приложения на платформу C# / .NET 10 (WinUI 3 / Windows App SDK) с современным Fluent-дизайном Windows 11, визуальными эффектами Mica/Acrylic и архитектурой MVVM.
2. Полная интеграция 15 медиаинструментов обработки видео, аудио, субтитров и контейнеров на базе консольных утилит FFmpeg, QAAC, eac3to, mkvmerge, DEE и yt-dlp.
3. Новый скрипт «Пересадка аудио» (в стиле DubSwap) для точного сведения аудиодорожек с нативной визуальной синхронизацией волн в GPU через Win2D Direct2D и математической компенсацией 21.33-мс задержки AAC кодера.
4. Сверхвысокая детализация осциллограмм уровня Adobe Audition: миллисекундный расчет огибающей звука (1000 Гц = 1 мс на пик) с SIMD-векторизацией, 5-уровневая пирамида детализации (LOD), масштабирование зума до 50 000 px/sec и фоновая сетка миллисекундных таймкодов.
5. Новый скрипт «Загрузка медиа» в категории «Сеть» для скачивания видео и аудио по ссылкам через yt-dlp с динамическим выбором разрешений, битрейтов, субтитров и автоматическим слиянием потоков в MKV.
6. Новые скрипты «Сдвиг аудио» (корректировка задержки/опережения с сохранением в FLAC/WAV) и «Сдвиг субтитров» (корректировка тайминга SRT, ASS, SSA и VTT в формате Aegisub).
7. Калькулятор сдвига таймингов с маскированным вводом времени в стиле Aegisub, автоматическим расчетом разности во времени, вставкой из буфера обмена и копированием результата.
8. Встроенная система переименования выходных файлов (PowerRename-style): regex и текстовый поиск/замена, автонумерация, переменные даты/времени/UUID, конструктор шаблонов имен в стиле HandBrake с живым предпросмотром.
9. Отдельное окно предпросмотра субтитров с фильтрацией по актёрам, стилям и эффектам, поиском по имени, ручным включением/отключением реплик, подсветкой тегов и CAPS-реплик.
10. Интерактивное дерево выбора дорожек с групповой фильтрацией, каскадным выделением, сортировкой вложений и автоматическим сбросом при переключении скриптов.
11. Drag-and-drop очередь файлов с автофильтрацией по расширениям, расчётом размера и отображением прогресса/ETA в реальном времени.
12. Настройки кодирования видео и аудио: целевой битрейт x265 (ABR), режим Lossless, апмикс 3.0/4.0/5.1 под Dolby, выбор разрядности WAV (16/24/32-bit), визуальный редактор ключевых слов.
13. Автоматическое управление внешними зависимостями (FFmpeg, eac3to, mkvmerge, DEE, yt-dlp, Node.js): фоновая загрузка, распаковка, проверка цельности и автообновление yt-dlp nightly через GitHub API.
14. Бесшумная автоматическая миграция в инсталляторе Inno Setup: при установке версии 2.0 инсталлятор автоматически находит и удаляет в тихом режиме прошлые версии 1.x, сохраняя пользовательские конфигурации `settings.json` в `LocalAppData`.
15. Автоматическая динамическая система регистрации скриптов: любые новые модули мгновенно добавляются в боковое меню навигации и на домашний экран приложения.
16. Интеграция с контекстным меню Проводника Windows («Открыть в KTools») с выбором скрипта и передачей файлов в единый экземпляр приложения (Single-Instance).
17. Перевод инсталлятора на пользовательский режим установки (Per-User в `%LOCALAPPDATA%\Programs\KTools`) без обязательных прав администратора (`PrivilegesRequired=lowest` и `PrivilegesRequiredOverridesAllowed=dialog`), а также автоматическое переключение записи рабочих утилит в `LocalAppData` при установке в защищенные папки `Program Files`.
18. Полноценное построчное выделение логов Fluent Design: удален внутренний перехват событий мыши у `TextBlock`, настроен стилевой контейнер `ListViewItem` с поддержкой выделения диапазонов через `Shift+Click`, индивидуального выбора через `Ctrl+Click`, полного выделения `Ctrl+A`, снятия выделения кликом в пустую область и копирования через ПКМ / `Ctrl+C`.
19. Умное автопереключение вкладок при Drag & Drop: если пользователь перетаскивает файлымышью на любой вкладке скрипта (например, на «Настройках» или «Дорожках»), приложение в момент наведения курсора автоматически мгновенно переключается на вкладку «Файлы» для удобного сброса.
20. Глобальный сброс фокуса с полей ввода (Issue #19): реализован `FocusHelper` на уровне каркаса `MainPage`. Нажатие `Enter` в однострочных полях ввода или клик мышью по любой свободной области окна теперь автоматически снимает фокус со сфокусированного контрола (`TextBox`, `NumberBox`, `AutoSuggestBox`). Локальные обработчики `KeyDown` удалены.

3. Реализована автоматическая очистка частично созданных или поврежденных выходных файлов при возникновении любых ошибок во всех скриптах медиаобработки (например, при нехватке места на диске), а не только при ручной отмене.
4. Исправлен парсинг прогресса и скорости кодирования QAAC при наличии дробной части в секундах.

# 1.5.0

### Добавлено

1. Поддержка аудио-контейнеров `.mka` в общем списке форматов и в модуле демуксинга.
2. Добавлена система управления временными файлами (`TempFileManager`): реализовано автоматическое отслеживание и очистка данных как при штатном выходе, так и при следующем запуске.
3. Добавлена функциональность прерывания работы скриптов: основная кнопка запуска теперь работает как переключатель (Выполнить/Остановить), позволяя безопасно останавливать активные дочерние процессы и автоматически удалять неполные выходные файлы.
4. Добавлены опции удаления исходного файла после обработки и прямой подмены оригинала (переименование результата в имя исходного файла) для модулей управления и замены потоков.
5. Добавлена поддержка навигации с помощью боковых кнопок мыши (кнопка «Назад») для возврата к предыдущим разделам интерфейса.
6. Автоматическая конвертация субтитров формата Timed Text и WebVTT в ASS при демуксинге.
7. Обогащение заголовков дорожек через pymediainfo при отсутствии данных от mkvmerge.
8. Различение дорожек с одинаковым языком: к субтитрам в дереве добавляется заголовок дорожки для уникальности.

### Исправлено

1. Устранено «состояние гонки» при массовой параллельной обработке: исправлены ошибки в менеджере настроек и подсистеме создания папок, из-за которых файлы могли сохраняться в некорректную директорию.
2. Исправлена логика исключения и замены дорожек: обеспечено корректное использование специфичных флагов `mkvmerge` для каждого типа потока и предотвращена «утечка» глав и тегов из исходных файлов.
3. Исправлены ошибки первого запуска `deew` и ошибки доступа при работе с путями, содержащими кириллицу.
4. Исправлен алгоритм замены потоков в контейнерах MKV: заменяемые дорожки сохраняют свою оригинальную позицию в файле и полностью наследуют все метаданные (язык, имя, флаги доступности и приоритета).
5. Исправлен выход элементов интерфейса за пределы окна при использовании очень длинных имен файлов и путей: реализовано их автоматическое сокращение в статус-баре и списках замен.
6. Исправлено зависание спиннера на вкладке «Дорожки» при сбое фонового технического анализа файлов (например, при отсутствии kt-ffprobe.exe или повреждении контейнера).

### Изменено

1. Оптимизировано отображение названия приложения в таскбаре Windows: удален информационный суффикс, теперь при наведении на иконку отображается только «K-Tools».
2. Оптимизирована архитектура приложения: внедрён паттерн проектирования Singleton для менеджера настроек и всех инфраструктурных раннеров (FFmpeg, FFProbe, mkvmerge и др.). Это устраняет их многократную инициализацию и решает проблему избыточных сообщений в логе.
3. Улучшена диагностика ошибок: теперь захватывается полный вывод `mkvmerge` (stdout и stderr) при сбоях.
4. Реализована автоматическая установка флагов «по умолчанию» и «принудительно» для всех дорожек, добавляемых через модуль муксинга из внешних файлов для их приоритетного выбора в плеерах.
5. Полностью переработан «Безопасный режим» для `deew`: теперь временные копии исходных файлов не создаются, что экономит место на диске и исправляет ошибки определения длительности потока.
6. Улучшена система защиты файлов: реализовано автоматическое разрешение конфликтов имен (добавление суффиксов `_1`, `_2`) и блокировка записи в файлы, занятые другими процессами.
7. Расширена поддержка кодека ALAC: реализовано сохранение в контейнер CAF (расширение `.alac`) для обеспечения совместимости с FFmpeg и внешними плеерами.
8. Интерфейс транскодирования теперь динамически скрывает несовместимые опции (например, упаковку в M4A для форматов, отличных от QAAC/AAC/ALAC).
9. Унифицирована обработка имен файлов (Path.stem) во всех модулях приложения для повышения стабильности сопоставления.
10. Улучшен интерфейс модуля демуксинга: реализована полноценная поддержка родительских чекбоксов для файлов, позволяющая массово выделять или снимать выбор со всех дорожек файла одним кликом.
11. Устранено замусоривание рабочих директорий лог-файлами eac3to: реализована автоматическая очистка файлов журнала (log*.txt) после завершения работы утилиты.
12. Категория «Муксинг» переименована в «Контейнеры» для упрощения навигации и соответствия общему стилю интерфейса.
13. Уменьшена длительность анимаций перехода между вкладками скриптов.
