# 2.0.0-csharp-dev

### Добавлено

1. Полный переход на C#, .NET 8 и WinUI 3 (Windows App SDK) с поддержкой Fluent-дизайна Windows 11; архитектура переведена на MVVM с поддержкой Native AOT.
2. Перенесены все инструменты медиаобработки на базе FFmpeg, QAAC, eac3to и mkvmerge: очистка метаданных, смена контейнера (с анализом совместимости кодеков без перекодирования), конвертация субтитров (ASS/SSA/SRT ↔ WebVTT/SRT/ASS), кодирование аудио (QAAC, AAC, MP3, FLAC, WAV и др.), изменение скорости аудио (пресеты PAL ↔ NTSC через eac3to), разделение многоканального аудио на моно-дорожки, извлечение аудио/видео/субтитров и встроенных шрифтов, сборка MKV с автопоиском сопутствующих дорожек по имени, управление потоками (удаление или сохранение выбранных дорожек) и другие.
3. Интерактивное дерево выбора дорожек с групповой фильтрацией, каскадным выделением и сортировкой вложений.
4. Drag-and-drop очередь файлов с автофильтрацией по расширениям, расчётом размера и отображением прогресса/ETA в реальном времени.
5. Менеджер зависимостей: автоматическое скачивание, распаковка и проверка внешних утилит (FFmpeg, eac3to, mkvmerge, DEE), включая фоновую установку и корректное удаление пакета декодеров eac3to.
6. Автообновление приложения: проверка, скачивание и тихая установка новых версий, в том числе пререлизов.
7. Встроенная система переименования выходных файлов (PowerRename-style): regex и обычный текстовый поиск/замена, автонумерация с заполнением нулями, переменные даты/времени/UUID, пользовательские шаблоны поиска и замены с сохранением в JSON, живой предпросмотр переименования с учётом смены расширения файла под целевой формат.
8. Отдельное окно предпросмотра субтитров (WinUI 3) с фильтрацией по актёрам, стилям и эффектам, поиском по имени, ручным включением/отключением отдельных реплик, подсветкой тегов разметки и CAPS-реплик, быстрым просмотром финального текста строки.
9. Настройки видеокодирования: целевой битрейт x265 (ABR) с авторасчётом мин/макс битрейта и буфера, режим Lossless, визуальный редактор ключевых слов для аудио и субтитров.
10. Раздел общих настроек программы: тема оформления, фон (Mica/Acrylic), правила перезаписи, пути экспорта, логирование.
11. CI/CD в GitHub Actions для автосборки релизов и пререлизов с динамическим версионированием.
12. Отображение FPS и битрейта в реальном времени в общей строке состояния при выполнении медиаобработки через FFmpeg (в пакетном режиме отображаются показатели первого активного на данный момент файла).
13. Базовые правила автоматического контроля качества и стиля кодирования для унификации разработки.
14. Инструменты статического анализа кода для контроля соблюдения принятых стандартов форматирования.
15. Интерфейсы для сервисов ядра и запуска консольных утилит для обеспечения слабой связанности.
16. Регистрация сервисов ядра и запуска внешних утилит в контейнере внедрения зависимостей (DI).
17. Внедрение зависимостей через конструктор (Constructor DI) для всех Runner-сервисов запуска внешних утилит (FFmpeg, eac3to, mkvmerge, QAAC, DEE) на инфраструктурном уровне.
18. Интеграция с контекстным меню Проводника Windows («Открыть в K-Tools») с выбором скрипта обработки и передачей выделенных файлов в одно запущенное окно (Single-Instance Redirection) без открытия дополнительных копий.
19. Включение по умолчанию поиска пререлизов в настройках обновлений.

1. Настроена фильтрация предупреждений статических анализаторов для обеспечения чистой сборки на этапе рефакторинга.
2. Интерфейс переработан под стиль Windows 11: NavigationView для бокового меню, закреплённые шапка и нижняя панель управления.
3. Рабочая панель скрипта разделена на вкладки «Файлы» и «Настройки»; очередь файлов переведена на ListView с кольцевым индикатором прогресса, лог событий — на виртуализированный список с поддержкой Mica/Acrylic.

5. Настройки сериализуются в JSON с поддержкой кириллицы; установщик собирается через Inno Setup со сжатием LZMA2.
6. Единое поведение снятия фокуса с полей ввода по Enter и клику в пустую область — распространено на все поля переименования и параметров скриптов.
7. Общая ревизия вёрстки настроек и параметров скриптов: выравнивание полей и меток, фиксированная ширина шаблонов и описаний, оптимизация отступов.

9. Настройки параллелизма и автоматического создания подпапки результатов объединены в соответствующие экспандеры (SettingsExpander); внутренние параметры (количество потоков, имя папки) автоматически деактивируются при отключении главных опций.
10. В поле выбора пути к папке логов теперь отображается фактический путь по умолчанию вместо статической заглушки, если пользователь не задал кастомную папку.
11. Устаревший статический блок «О программе» заменен на современный свертываемый SettingsExpander с информацией о версии, лицензии и ссылками на репозиторий GitHub.
12. Нестандартная рамка уведомления о доступных обновлениях в настройках заменена на нативный однострочный элемент InfoBar от WinUI 3 с кнопкой справа; на главном экране реализован аккуратный закрываемый баннер обновлений вместо навязчивого модального окна.
13. Добавлен скрытый раздел «Параметры отладки» (активируется 7-кратным нажатием на версию приложения) с опцией эмуляции старой версии (1.0.0) для удобного тестирования системы обновлений.
14. Удален неиспользуемый спекулятивный код для оптимизации структуры проекта.
15. Реализовано наследование интерфейсов в классах ядра и инфраструктуры. Разорвана циклическая связь между логированием и менеджером настроек. Добавлен нестатический сервис путей.
16. Интеграция DI для страниц приложения переведена на нативный подход WinUI 3 с автоматическим сохранением системных анимаций переходов и встроенной истории навигации.
17. Обновлен и расширен план архитектурного рефакторинга приложения: добавлены детальные этапы по многопоточности и маршалингу событий UI в DispatcherQueue, переходу на скомпилированные привязки x:Bind, внедрению IHttpClientFactory с политиками устойчивости Polly, централизованной обработке модальных диалогов с привязкой к XamlRoot и интернационализации интерфейса через MRT Core.

# 1.7.0

### Добавлено

1. Новый инструмент «Кодирование видео» (программное/аппаратное кодирование, вшивание субтитров, удаление строк, 10-битный цвет, расчет битрейта и ETA) и приоритет языков при автовыборе дорожек с ISO-валидацией.
2. Расширение возможностей скрипта конвертации субтитров «ASS/SRT → VTT»: добавлена фильтрация строк по полю «Эффект», КАПСу, поддержка формата SRT и возможность ручного исключения строк.
3. Развитие аудио-конвертера: автоматический апмикс конфигураций 3.0 и 4.0 под Dolby, предупреждения о несовместимых параметрах длительности, выбор разрядности WAV (16/24/32-bit/32-bit Float).
4. Добавление поддержки контейнеров `.m2ts`, `.ts` и аудио-сегментов `.m4s` (DASH).
5. Повышение информативности: вкладка «Логи» для мониторинга в реальном времени с возможностью смены папки сохранения журналов в настройках.
6. Модуль обновлений и зависимостей: автоматическое/ручное обновление с GitHub (включая пре-релизы) со всплывающими оповещениями, а также система отложенной динамической загрузки внешних бинарных утилит (FFmpeg, Dolby, MKVToolNix, eac3to) с карточками статусов, автопереходом при первом старте и баннерами быстрой установки.

### Изменено

1. Оптимизация обработки медиа: асинхронный фоновый анализ дорожек в контейнерах, автоупаковка AAC/QAAC/ALAC в M4A для фикса длительности, расширение списка форматов при ремуксинге с проверкой совместимости кодеков, оптимизация фильтров демуксинга и прямой запрос к GPU для проверки NVENC/CUVID/AV1.
2. Улучшение юзабилити и плавности UI: ускорение запуска приложения, оптимизация анимаций и скролла, двухвкладочная компоновка страниц скриптов («Файлы» и «Настройки»), цветовые индикаторы статуса файлов и разгрузка статус-бара от длинных путей к файлам.
3. Системные улучшения: автоматический перенос старых файлов конфигурации пользователей, автопереключение на папку профиля пользователя при нехватке прав записи и перенос отображения версии программы в блок обновлений.
4. Оптимизация сборки и дистрибуции: переход на компиляцию через Nuitka (сокращение веса установщика с ~400 до ~50 МБ, раздельная сборка), автоматическое пересоздание тестовых релизов на GitHub и обновление экрана зависимостей с переходом на высокоэффективное сжатие LZMA2 (`.tar.xz`).

2. Добавлена система управления временными файлами (`TempFileManager`): реализовано автоматическое отслеживание и очистка данных как при штатном выходе, так и при следующем запуске.
3. Добавлена функциональность прерывания работы скриптов: основная кнопка запуска теперь работает как переключатель (Выполнить/Остановить), позволяя безопасно останавливать активные дочерние процессы и автоматически удалять неполные выходные файлы.
4. Добавлены опции удаления исходного файла после обработки и прямой подмены оригинала (переименование результата в имя исходного файла) для модулей управления и замены потоков.

8. Различение дорожек с одинаковым языком: к субтитрам в дереве добавляется заголовок дорожки для уникальности.

### Исправлено

1. Устранено «состояние гонки» при массовой параллельной обработке: исправлены ошибки в менеджере настроек и подсистеме создания папок, из-за которых файлы могли сохраняться в некорректную директорию.
2. Исправлена логика исключения и замены дорожек: обеспечено корректное использование специфичных флагов `mkvmerge` для каждого типа потока и предотвращена «утечка» глав и тегов из исходных файлов.
3. Исправлены ошибки первого запуска `deew` и ошибки доступа при работе с путями, содержащими кириллицу.
4. Исправлен алгоритм замены потоков в контейнерах MKV: заменяемые дорожки сохраняют свою оригинальную позицию в файле и полностью наследуют все метаданные (язык, имя, флаги доступности и приоритета).
5. Исправлен выход элементов интерфейса за пределы окна при использовании очень длинных имен файлов и путей: реализовано их автоматическое сокращение в статус-баре и списках замен.
6. Исправлено зависание спиннера на вкладке «Дорожки» при сбое фонового технического анализа файлов (например, при отсутствии kt-ffprobe.exe или повреждении контейнера).


### Изменено

1. Оптимизировано отображение названия приложения в таскбаре Windows: удален информационный суффикс, теперь при наведении на иконку отображается только «K-Tools».
2. Оптимизирована архитектура приложения: внедрён паттерн проектирования Singleton для менеджера настроек и всех инфраструктурных раннеров (FFmpeg, FFProbe, mkvmerge и др.). Это устраняет их многократную инициализацию и решает проблему избыточных сообщений в логе.
3. Улучшена диагностика ошибок: теперь захватывается полный вывод `mkvmerge` (stdout и stderr) при сбоях.
4. Реализована автоматическая установка флагов «по умолчанию» и «принудительно» для всех дорожек, добавляемых через модуль муксинга из внешних файлов для их приоритетного выбора в плеерах.

7. Расширена поддержка кодека ALAC: реализовано сохранение в контейнер CAF (расширение `.alac`) для обеспечения совместимости с FFmpeg и внешними плеерами.

10. Улучшен интерфейс модуля демуксинга: реализована полноценная поддержка родительских чекбоксов для файлов, позволяющая массово выделять или снимать выбор со всех дорожек файла одним кликом.
