# 2.0.0-csharp-dev

### Добавлено

1. Инициализация профессиональной архитектуры приложения на C# и .NET 8 с использованием Windows App SDK и WinUI 3.
2. Реализация главного экрана приложения с интерактивными карточками скриптов, распределенными по оригинальным категориям (Видео, Аудио, Контейнеры, Субтитры).
3. Интеграция динамического эффекта подсветки и изменения курсора мыши на "руку" при наведении на интерактивные карточки.
4. Внедрение механизма автоматического сжатия и сворачивания бокового меню навигации по умолчанию при запуске.
5. Настройка точных геометрических размеров главного окна приложения в соответствии с оригинальной версией.
6. Интеграция официальной библиотеки Windows Community Toolkit для использования готовых профессиональных элементов управления.
7. Интеграция подсистемы управления внешними зависимостями с автоматической фоновой загрузкой, расчетом скорости скачивания и распаковкой через системные средства декомпрессии.
8. Реализация страницы настройки внешних компонентов в виде аккуратных, плотных вертикальных карточек со статусами, прогресс-барами и кнопками управления, полностью избавленных от избыточных пустых пространств.
9. Добавление навигации во вкладку компонентов на боковой панели с автопроверкой и редиректом при первом запуске.
10. Интеграция кнопки «Открыть папку» в панель быстрых действий для мгновенного перехода в изолированную локальную директорию бинарников в Проводнике Windows.
11. Разработка универсальной рабочей панели запуска скриптов с двухвкладочной компоновкой («Файлы» и «Настройки»), интегральным прогресс-баром и встроенным консольным логом.
12. Создание декларативной схемы параметров скриптов с автоматической динамической генерацией Fluent-виджетов настроек на странице параметров с автосохранением.
13. Разработка Drag-and-Drop очереди файлов с автоматической фильтрацией допустимых расширений под каждый скрипт, расчетом размера и индивидуальными прогресс-барами.
14. Реализация первого полноценного скрипта медиаобработки для очистки метаданных с запуском утилиты FFmpeg и автоматическим фоллбэком на имитацию.
15. Разработка страницы общих настроек приложения с возможностью управления темой оформления, правилами перезаписи, путями экспорта и кнопкой полного сброса параметров.
16. Автоматическая запись всех параметров по умолчанию в файл настроек при первом запуске программы без необходимости перехода по вкладкам скриптов.
17. Создание централизованного класса глобальных констант для хранения неизменяемых параметров, расширений форматов, языковых кодов и метаданных всех скриптов.
18. Полноценная реализация скрипта разборщика медиаконтейнеров на C# с поддержкой извлечения аудиодорожек, видеопотоков, субтитров и встроенных шрифтов.
19. Интеграция графического интерактивного дерева дорожек с поддержкой группового выбора элементов для всех импортированных файлов.
20. Интеграция панели динамической фильтрации дорожек в интерфейс выбора потоков с группировкой по категориям (видео, аудио, субтитры и вложения).
21. Реализация динамической фильтрации встроенных шрифтов и вложений по расширению и по части имени файла.
22. Внедрение графических информационных бейджей для кнопок-фильтров дорожек для визуализации количества выбранных правил.
23. Интеграция контейнера внедрения зависимостей для централизованного управления жизненным циклом сервисов и моделей представления.
24. Реализация специализированных системных служб навигации, диалоговых окон и дескрипторов окон для разделения бизнес-логики и интерфейса.
25. Создание глобальных конвертеров логических значений для повторного использования в XAML-разметке.
26. Реализация полноценного скрипта конвертации контейнера видеофайлов без перекодирования на основе вызова утилиты FFmpeg с проверкой совместимости кодеков.
27. Создание общих вспомогательных функций в базовом классе скриптов для безопасного сохранения результатов, удаления оригиналов и корректной обработки прерывания процессов.
28. Реализация полноценного скрипта конвертации субтитров на C# с поддержкой очистки форматирования, удаления CAPS-реплик и экспорта результатов в форматы VTT, SRT и ASS.
29. Разработка нативного C# парсера файлов субтитров в форматах ASS/SSA и SRT с автоматическим определением и поддержкой кодировок UTF-8 и Windows-1251.
30. Реализация полноценного скрипта кодирования аудио на C# с поддержкой перекодирования звука во множество форматов через FFmpeg и True VBR кодирования в Apple AAC через утилиту QAAC.
31. Реализация полноценного скрипта изменения скорости аудио (PAL ↔ NTSC) на C# с поддержкой форматов FLAC и WAV на базе утилиты eac3to.
32. Реализация полноценного скрипта разделения многоканального аудио на моно-WAV файлы на C# с опциональной автоматической склейкой в стереопары через FFmpeg.


### Изменено

1. Оптимизация компоновки интерфейса главного экрана: удалены лишние отступы контейнера навигации для прижатия полосы прокрутки к правому краю окна, что обеспечило стабильное отображение карточек скриптов ровно в два столбца.
2. Интеграция нативных интерактивных карточек настроек из Windows Community Toolkit с поддержкой трехмерного эффекта наклона при клике, курсора руки и стандартных эффектов наведения Windows 11.
3. Перенос заголовка программы и ее описания из прокручиваемой области в закрепленную верхнюю контентную панель с отключением встроенных заголовков меню, что полностью устранило избыточную высоту шапки и прижало текст к левому краю.
4. Исправление структуры меню навигации приложения и устранение ошибок компиляции интерфейса.
5. Оптимизация системы роутинга боковой панели и интеграция программного переключения страниц с синхронизацией пунктов меню и обработкой вызова общих настроек.
6. Модернизация горизонтальных вкладок на странице управления скриптами с переходом на навигацию NavigationView, добавлением наглядных Fluent-иконок для страниц файлов и параметров и плавным переключением контента.
7. Реорганизация верстки параметров скриптов: параметры одной группы теперь объединяются в единую карточку-контейнер Border с аккуратными внутренними отступами и разметкой строк, полностью соответствующей оригинальному виду.
8. Модернизация списка файлов в очереди: отображение заменено на ListView с поддержкой множественного выбора и кольцевыми прогресс-барами со встроенными иконками статусов.
9. Оптимизация интерфейса во время выполнения: список файлов в очереди теперь остается полностью активным и доступным для прокрутки во время выполнения обработки скрипта.
10. Перегруппировка элементов очереди файлов: кольцевой прогресс-бар и иконка статуса перенесены в правую часть строки (слева от кнопки удаления), а названия файлов теперь выровнены по левому краю.
11. Оптимизация производительности страницы отображения журналов логов за счет исключения избыточных вызовов считывания контента и частых переключений блокировок документа, что устранило задержки при ее открытии.
12. Настройка сериализатора параметров с использованием расслабленного Unicode-кодировщика, что позволило сохранять имена секций скриптов и строковые параметры на кириллице в исходном читаемом виде.
13. Увеличение размера графической кнопки удаления файлов во всех списках очереди для повышения точности и удобства взаимодействия с интерфейсом.
14. Модернизация визуального оформления дерева выбора: иконка аудиодорожек заменена на более подходящий графический символ динамика.
15. Модернизация интерфейса выбора дорожек: добавлен горизонтальный навигационный виджет для быстрого переключения вкладок категорий фильтров.
16. Оптимизация системы выбора: реализована каскадная синхронизация выбора родительских файлов и их дочерних потоков в интерактивном дереве.
17. Модернизация интерфейса фильтрации дорожек: громоздкие статические панели заменены компактной горизонтальной строкой кнопок с выпадающими меню (Flyouts), что полностью устранило проблему двойного скроллинга.
18. Интеграция динамического обновления текстовых меток кнопок фильтрации с выводом количества активных правил.
19. Оптимизация компоновки дерева дорожек: возвращен независимый внутренний скроллинг с растягиванием дерева на всю свободную высоту экрана при закрепленной сверху строке фильтров.
20. Добавление красивых тематических иконок для всех вкладок категорий и кнопок-фильтров дорожек.
21. Изменение логики выбора потоков по умолчанию: теперь при первом добавлении медиафайлов все чекбоксы дорожек и шрифтов в дереве остаются выключенными.
22. Внедрение ограничений на масштабирование окна: минимальный размер главного окна ограничен габаритами по умолчанию (800 x 960 пикселей) без блокировки возможности увеличения окна в большую сторону.

25. Реализация горизонтальной прокрутки для панели кнопок-фильтров с фиксацией чекбокса массового выбора слева и полным скрытием полосы прокрутки с экрана.
