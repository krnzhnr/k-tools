# План дальнейшей миграции скриптов KTools с Python на C#

Этот документ содержит пошаговый план переноса оставшихся скриптов медиаобработки из Python-версии приложения в C#-версию KTools.App (версия 2.0.0-csharp-dev) на основе стабильной архитектуры MVVM + DI.

## 2. Предлагаемый план поэтапной миграции

Для минимизации рисков и поэтапной интеграции оставшиеся скрипты разбиты на логические фазы по уровню сложности и зависимостям.

### Фаза 1: Простые скрипты и субтитры (Выполнено)
- **Скрипт «Конвертация контейнера»** — **РЕАЛИЗОВАН ПОЛНОСТЬЮ**:
  - Быстрый ремуксинг потоков (копирование кодеков) в MKV/MP4 на базе FFmpeg.
- **Скрипт «Конвертация субтитров»** — **РЕАЛИЗОВАН БАЗОВО**:
  - Нативный C# парсер текстовых файлов SSA/ASS/SRT с чисткой оформления и CAPS-реплик.
  - *План улучшения*: Внедрить интерактивные UI-функции (фильтрацию реплик по актерам/стилям/эффектам, ручное исключение строк и окно предпросмотра).

### Фаза 2: Аудио-скрипты (qaac, eac3to, DEE) (Выполнено)
- **Скрипт «Кодирование аудио»** — **РЕАЛИЗОВАН ПОЛНОСТЬЮ**:
  - Перекодирование звука через FFmpeg и True VBR кодирование в Apple AAC через qaac во временной папке.
- **Скрипт «Даунмикс в Stereo»** — **РЕАЛИЗОВАН ПОЛНОСТЬЮ**:
  - Генерация XML-конфигурации и запуск Dolby Encoding Engine через `DeeRunner` или EBU R128 нормализация через FFmpeg.
- **Скрипт «Изменение скорости аудио»** — **РЕАЛИЗОВАН ПОЛНОСТЬЮ**:
  - PAL ↔ NTSC тайм-стретчинг и тон-коррекция с использованием `Eac3toRunner` для экспорта в FLAC/WAV.
- **Скрипт «Разделение каналов»** — **РЕАЛИЗОВАН ПОЛНОСТЬЮ**:
  - *Источник*: `audio_splitter.py`
  - *Технология*: Разделение многоканального звука на моно-WAV файлы с помощью eac3to и склейка стереопар через FFmpeg.

### Фаза 3: Сложные скрипты контейнеров (Выбор дорожек) (В процессе)
- **Скрипт «Извлечение потоков»** — **РЕАЛИЗОВАН ПОЛНОСТЬЮ**:
  - Потоковое извлечение видео, аудио, субтитров и шрифтов через FFmpeg с использованием стабильного дерева выбора `TrackSelectionControl`.
- **Скрипт «Сборка MKV»** — **РЕАЛИЗОВАН ПОЛНОСТЬЮ**:
  - Объединение видео, звуковых дорожек и субтитров через `MkvmergeRunner`.
  - Уникальное табличное представление для группировки сопутствующих файлов по базовому имени в одну строку, сжатые отступы, поддержка ProgressRing и быстрое удаление.
- **Скрипт «Управление потоками»** — **РЕАЛИЗОВАН ПОЛНОСТЬЮ**:
  - Удаление нежелательных дорожек или сохранение только выбранных элементов дерева (`TrackSelectionControl`).
  - Поддерживает транскодирование в M4A (для одиночных аудиодорожек) и быстрое прямое копирование потоков (FFmpeg/mkvmerge).
- **Скрипт «Замена потоков»** (в очереди):
  - *Источник*: `stream_replacer.py`
  - *Технология*: Замена существующих дорожек в MKV на внешние аудиофайлы/субтитры.

### Фаза 4: Сложная видеообработка (В очереди)
- **Скрипт «Кодирование видео»** (в очереди):
  - *Источник*: `video_processor.py`
  - *Технология*: 10-битное кодирование x264/x265, автоматический расчет битрейта, использование аппаратного ускорения (NVENC/QSV), обрезка кадров и вшивание графических/текстовых субтитров.
