### Шаг 1️⃣: Создать новый MSIX пакет (5 мин)

1. Откройте **Visual Studio**
2. Откройте проект **KTools.App**
3. В меню выберите: **Project → Package and Publish → Create App Packages**
4. Выберите версию **2.0.0** (или выше)
5. Нажмите **Create**

**Результат**: новый файл `.msix` на диске

---

### Шаг 2️⃣: Установить и протестировать (5 мин)

```powershell

# Удалите старую версию если она установлена
Get-AppxPackage -Name "*KTools*" | Remove-AppxPackage -AllUsers

# Установите новый пакет
# (замените путь на ваш путь к MSIX файлу)
Add-AppxPackage -Path "C:\путь\к\KTools.App_2.0.0.0_x86.msix"

# Запустите приложение через Пуск или:
ktools-winui
```

## 🆘 ЕСЛИ ПРОБЛЕМА ОСТАЕТСЯ

### Проблема 1: Ошибка при скачивании FFMPEG

**Решение**:
1. Проверьте что это новый MSIX пакет (версия 2.0.0+)
2. Удалите и переустановите пакет
3. Проверьте что приложение видит себя как MSIX:
   ```powershell
   # Это должно вернуть "KTools-WinUI"
   [Environment]::GetEnvironmentVariable("PACKAGE_NAME", "User")
   ```

### Проблема 2: Файлы не появились в LocalAppData

**Решение**:
```powershell
# Проверьте права на запись
"test" | Out-File -FilePath "$env:LOCALAPPDATA\test.txt" -Force
Remove-Item "$env:LOCALAPPDATA\test.txt" -Force

# Если ошибка → проблема с правами пользователя
# Свяжитесь с администратором
```

### Проблема 3: Старые файлы остались в Program Files

**Решение**:
- Не удаляйте вручную (они всё равно не нужны)
- Новые файлы будут загружены в `LocalAppData`
- Приложение автоматически найдет файлы в обоих местах

## 📊 ЧТО ИЗМЕНИЛОСЬ В КОДЕ

### PathManager.cs

**ДО** (❌ Проблема):
```csharp
public static string GetBinDirectory()
{
	return Path.Combine(BaseDir, "bin");  // Всегда Program Files!
}
```

**ПОСЛЕ** (✅ Исправлено):
```csharp
public static string GetBinDirectory()
{
	// Проверяем тип приложения
	if (!string.IsNullOrEmpty(Environment.GetEnvironmentVariable("PACKAGE_NAME")))
	{
		// MSIX → LocalAppData (есть права)
		return Path.Combine(
			Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData),
			"KTools", "bin");
	}
	// Обычное приложение → как раньше
	return Path.Combine(BaseDir, "bin");
}
```

### DependencyManager.cs

**ДО** (❌ Проблема):
```csharp
Directory.CreateDirectory(destinationFolder);  // Падает с ошибкой доступа!
```
