# Аудит безопасности удаления eac3to Decoder Pack

## Где вручную найти деинсталлятор

Деинсталлятор eac3to Decoder Pack находится в двух местах:

### Файлы на диске
| Файл | Путь | Размер | Статус |
|------|------|--------|--------|
| Деинсталлятор (исполняемый файл Inno Setup) | `C:\Windows\unins000.exe` | 1,183,089 bytes | **ЕСТЬ** |
| Данные деинсталлятора (манифест файлов для удаления) | `C:\Windows\unins000.dat` | 19,567 bytes | **ЕСТЬ** |

### Запись в реестре Windows
Открой `regedit.exe` и перейди по следующему пути:

```
HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall\{167887DA-6C4F-4265-8139-8750A543FD52}_is1
```

Там увидишь:
- **DisplayName** = `eac3to Decoder Pack 1.4`
- **UninstallString** = `"C:\Windows\unins000.exe"`

> [!TIP]
> Ты также можешь найти eac3to Decoder Pack в стандартном интерфейсе Windows:
> `Панель управления` → `Программы и компоненты` (или `Параметры` → `Приложения` → `Установленные приложения`).
> Там он будет отображаться как **«eac3to Decoder Pack 1.4»**.

## Как работает удаление: два сценария

### Сценарий 1: Официальный деинсталлятор (приоритетный)
Наш код сначала ищет в реестре `UninstallString` по GUID `{167887DA-6C4F-4265-8139-8750A543FD52}_is1` и, если находит файл `C:\Windows\unins000.exe`, запускает его с флагами:
```
"C:\Windows\unins000.exe" /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
```
Это **самый безопасный** вариант — Inno Setup сам знает, какие файлы были установлены (данные хранятся в `unins000.dat`), и удаляет только их, корректно разрегистрируя COM/DirectShow-компоненты.

### Сценарий 2: Ручное удаление через .bat (резервный)
Запускается **только если** `unins000.exe` не найден или не существует (т.е. кто-то вручную удалил деинсталлятор, но файлы декодеров остались в системе). Генерирует временный `.bat` и запускает его с одним UAC-запросом.

Это наша защитная мера: эти файлы могут использоваться другими старыми программами. Если удалить их, программы на VC++ 7.1 перестанут запускаться.
> 
> **Это значит, что наш резервный метод БЕЗОПАСНЕЕ, чем оригинальный деинсталлятор** в отношении общих системных библиотек.

## Потенциальные риски и защитные меры

### ✅ Что НЕ удаляется (защищено)

| Элемент | Почему не удаляем |
|---------|-------------------|
| `msvcr71.dll` / `msvcp71.dll` | Общие библиотеки VC++ 2003, могут быть нужны другим программам |
| `C:\Windows\unins000.exe` / `.dat` | Если существуют — мы используем сценарий 1, Inno Setup сам их подчистит |
| Любые файлы за пределами `SysWOW64`, `System32`, `C:\Windows` | Наш код работает только с фиксированным списком файлов в системных директориях |

### ✅ Защита от ошибок

| Защитная мера | Как реализовано |
|---------------|----------------|
| Каждый `del` / `rd` защищён `if exist` | Если файла нет — команда просто пропускается, без ошибки |
| `reg delete` подавляет ошибки `>nul 2>&1` | Если ключа реестра нет — команда игнорируется |
| Весь батник в `try/finally` | Временный `.bat` файл удаляется даже при ошибке |
| UAC через `runas` | Пользователь явно подтверждает повышение прав |
| `regsvr32 /u /s` — тихий режим | Не показывает никаких диалогов, не зависает |

### ⚠️ Единственный теоретический риск

> [!WARNING]
> **Имя `unins000.exe`** — это стандартное имя деинсталлятора Inno Setup. Если на компьютере установлена **другая** программа, использующая Inno Setup и записавшая свой деинсталлятор в `C:\Windows\unins000.exe`, то запуск сценария 1 может удалить **ту** программу вместо декодеров.
>
> **Однако наш код защищён**: мы ищем `UninstallString` **строго** по GUID `{167887DA-6C4F-4265-8139-8750A543FD52}_is1` и по `DisplayName`, содержащему `"eac3to Decoder Pack"`. Мы не запускаем произвольный `unins000.exe` — мы запускаем только тот путь, который прописан в записи реестра, принадлежащей именно eac3to Decoder Pack.
