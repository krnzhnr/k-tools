## 🧪 Как протестировать

### Для MSIX версии

```powershell
# Шаг 1: Создать новый MSIX пакет
cd F:\Programming\Utils\k-tools\src-csharp
dotnet build -c Release

# Шаг 2: Запустить Visual Studio и создать MSIX через меню
# Project > Package and Publish > Create App Packages

# Шаг 3: Установить пакет
Add-AppxPackage -Path "путь/к/KTools.App_2.0.0.0_x86.msix"

# Шаг 4: Запустить приложение
# Пуск > KTools-WinUI

# Шаг 5: Проверить страницу зависимостей
# Откройте вкладку "Зависимости" или "Settings"

# Шаг 6: Скачать FFMPEG
# Нажмите кнопку скачивания
# ✅ Не должно быть ошибок доступа

# Шаг 7: Проверить папку
$kToolsPath = "$env:LOCALAPPDATA\KTools\bin\ffmpeg"
Get-ChildItem $kToolsPath  # Должны быть файлы kt-ffmpeg.exe и т.д.
```

### Для обычной версии

```powershell
# Запустить как обычно
cd F:\Programming\Utils\k-tools\src-csharp
dotnet build
dotnet run --project KTools.App/KTools.App.csproj

# Проверить что поведение идентично
# - Зависимости скачиваются в bin\
# - Конфиг в папке проекта или LocalAppData
# - Никаких ошибок доступа
```
