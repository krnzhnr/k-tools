# Спецификация Цепочки Видеофильтров и Модулей Видеокодирования

Документ сохранен для сохранения всей архитектуры, порядка применения видеофильтров и нюансов работы с кодеками/субтитрами при последующей реализации.

---

## 1. Порядок применения Видеофильтров (Priority & Order)

Строка `-vf` в FFmpeg собирается через запятую в **строгом приоритетном порядке**:

```text
[SubtitlesFilter (Priority 0)] -> [AutoCropFilter (Priority 10)] -> [AutoScaleFilter (Priority 20)]
```

### 1.1 `SubtitlesFilter` (Приоритет: 0)
- **Цель**: Вшивание субтитров (Hardsub).
- **Синтаксис**:
  - На Windows все слэши в путях приводятся к экранированным прямолинейным: `.Replace("\\", "/").Replace(":", "\\:")`.
  - Формируемый аргумент:
    ```text
    subtitles='C\:/Users/.../temp.ass':fontsdir='C\:/Users/.../fonts'
    ```
- **Параметры применения**:
  - Применяется при `burn_subtitles_enabled == true` и наличии существующего `.ass` файла.

### 1.2 `AutoCropFilter` (Приоритет: 10)
- **Цель**: Автоматическое удаление черных полос (Letterboxing/Pillarboxing).
- **Логика детекции**:
  - Запуск зондирования через `ffmpeg -ss <skip_sec> -i <file> -vframes 10 -vf cropdetect=<threshold>:<round>:0 -f null -`.
  - Извлечение значений `crop=w:h:x:y`.
- **Синтаксис в -vf**: `crop=W:H:X:Y`.

### 1.3 `AutoScaleFilter` (Приоритет: 20)
- **Цель**: Масштабирование видео строго пропорционально (без анаморфирования) с приведением к стандартному ряду.
- **База расчёта**: разрешение кадра **после кропа** (`maxCropW x maxCropH`, если кроп применён и включён), иначе исходное разрешение видеодорожки.
- **Единственный параметр — коэффициент** (`resize_factor`: `0.25` / `0.5` / `0.75` — уменьшение, `1.5` / `2.0` — увеличение). Отдельных настроек «по высоте / по ширине» нет.
- **Снап к стандартному ряду**: высота `база × коэффициент` приводится к ближайшей из ряда `240 / 360 / 480 / 720 / 1080 / 1440 / 2160 / 4320` (при равной удалённости — меньшая), ширина вычисляется пропорционально от неё с округлением до чётной (требование `yuv420p`).
- **Канонический синтаксис в -vf** (явное разрешение, вычисленное от базы после кропа):
  ```text
  scale=1920:1080:flags=lanczos
  ```
  Примеры: база `3840x2160` × `0.5` → `scale=1920:1080:flags=lanczos`; покропленная `3840x1600` × `0.5` (сырая высота 800 → снап 720) → `scale=1728:720:flags=lanczos`; `1920x1080` × `0.75` (сырая высота 810 → снап 720) → `scale=1280:720:flags=lanczos`.
- **Поддерживаемые алгоритмы**: `lanczos`, `bicubic`, `bilinear`, `spline` (флаг `:flags=`).
- **Апскейл**: по умолчанию запрещён (`resize_allow_upscale = false`) — если целевое разрешение больше текущего после кропа, фильтр не применяется, пишется событие `scale.skipped` с причиной `UpscaleDenied`.
- **Логирование**: `scale.applied` (уровень Info, статус Succeeded — исходное и целевое разрешение, алгоритм), `scale.skipped` (уровень Debug, статус Skipped — причина `UpscaleDenied` / `TargetEqualsSource` / `ResolutionUnknown` / `InvalidFactor` / `InvalidTarget`).
- **Превью в списке файлов**: капсула показывает `исходное ➔ [после кропа ➔] новое` заранее, до запуска. Кроп выключен — расчёт сразу от исходника. Кроп включён — тихое фоновое зондирование очереди строго по одному файлу с паузой между файлами (без параллелизма), на время кодирования фон встаёт на паузу. Результаты кропа кэшируются (файл + слепок всех параметров кропа) и переиспользуются кодированием; изменение любого параметра кропа сбрасывает весь кэш и пересчитывает всё.
- **Полная цепочка** (строгий порядок через запятую):
  ```text
  -vf "subtitles=filename='...':fontsdir='...',crop=3840:1600:0:280,scale=1728:720:flags=lanczos"
  ```

## 2. Важные нюансы работы с Энкодерами

1. **HEVC / H.265**:
   - Для контейнера `.mp4` при использовании HEVC обязателен тэг `-tag:v hvc1` (для воспроизведения в Apple QuickTime / iOS).
   - **Внимание**: Для `av01` (AV1) или `h264` этот флаг **НЕ должен передаваться**, иначе FFmpeg падает с ошибкой `Tag hvc1 incompatible with output codec`.

2. **AV1 (libsvtav1)**:
   - Не поддерживает честный математический Lossless через `-crf 0` (при `crf 0` улетает в `crf 35`).
   - Для режима Near-Lossless / Visually Lossless в `libsvtav1` нужно использовать **`-crf 1`**.

3. **Связка UI и полей `auto_bitrate`**:
   - Поля `min_bitrate`, `max_bitrate` и `bufsize` при включении `auto_bitrate` должны оставаться **видимыми**, но делать свойство `IsEnabled = false`.
