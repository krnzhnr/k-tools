# План тестирования проекта K-Tools

Этот документ содержит детальный план и чек-лист для написания юнит-тестов и обеспечения полного тестового покрытия всех 12 медиа-скриптов, парсеров вывода консольных утилит, сервисов ядра и моделей представления (ViewModels).

## 📋 Чек-лист тестирования

- [x] **FFmpegOutputParserTests**:
  - [x] Парсинг строк прогресса с FPS, временем, размером и битрейтом.
  - [x] Обработка некорректных строк и пустых значений без сбоев.
- [x] **QaacOutputParserTests**:
  - [x] Расчет процентов выполнения на основе лога QAAC.
  - [x] Парсинг скорости кодирования и оценка времени (ETA).

  - [x] Валидация конвертации тегов ASS в WebVTT.

### 2. Тестирование 12 медиа-скриптов ( CLI-аргументы, схемы параметров и пути ) ⚙️

#### 2.1 MetadataCleanupScriptTests (Очистка метаданных)
- [x] Валидация схемы: наличие параметров `Suffix` и `DeleteOriginal`.
- [x] Проверка CLI: генерация аргументов `-map_metadata -1` и копирования потоков `-c:v copy -c:a copy` для FFmpeg.
- [x] Тестирование удаления исходного файла при включенном `DeleteOriginal`.
- [x] Проверка симуляции работы при отсутствии установленного FFmpeg.

#### 2.2 VideoEncodingScriptTests (Кодирование видео)
- [x] Проверка авторасчета битрейта (мин/макс/размер буфера) на основе целевого битрейта.
- [x] Валидация CLI при аппаратном кодировании: генерация аргументов `-c:v h264_nvenc` и `-c:v hevc_nvenc`.
- [x] Валидация CLI при программном кодировании: генерация аргументов `-c:v libx265` с пресетами CRF.
- [x] Проверка режима Lossless (генерация флагов `-crf 0` или `-qp 0`).
- [x] Проверка бага #11: Корректный возврат/сброс пресета NVENC и других зависимых полей (битрейт, качество) к исходным значениям при отключении режима Lossless.
- [x] Тестирование вшивания субтитров (burn-in): генерация фильтра `-vf subtitles=...`.
- [x] Проверка логики извлечения и временного сохранения встроенных шрифтов.
- [x] Тестирование асинхронного определения поддержки NVENC на GPU.

#### 2.3 ContainerConversionScriptTests (Конвертация контейнера)
- [x] Проверка анализа совместимости кодеков без перекодирования (режим stream copy `-c copy`).
- [x] Валидация перепаковки форматов `.m2ts`, `.ts`, `.m4s` в `.mp4` или `.mkv`.
- [x] Проверка обработки ситуации с несовместимыми кодеками (выброс исключения или авто-перевод в транскодирование).

#### 2.4 AudioEncodingScriptTests (Кодирование аудио)
- [ ] Валидация CLI кодировщика QAAC (битрейт, пресеты качества, True Variable Bitrate).
- [ ] Проверка кодирования через FDK-AAC, MP3, FLAC, WAV (битность 16/24/32-bit Float).
- [ ] Тестирование автоупаковки выходных потоков AAC/ALAC в контейнер M4A (`.m4a`).
- [ ] Проверка сокрытия несовместимых опций упаковщика для форматов, отличных от AAC/ALAC.

#### 2.5 AudioDownmixScriptTests (Стерео-даунмикс)
- [ ] Проверка даунмикса конфигураций 5.1/7.1 в 2.0 (стерео) через Dolby Encoder (DEE).
- [ ] Валидация CLI аргументов для утилиты `deew.py` (пресеты стерео, LFE attenuation).
- [ ] Проверка резервного даунмикса через FFmpeg (фильтр `-af "pan=stereo|..."`) при отсутствии лицензии Dolby.
- [ ] Проверка детекции существования выходного файла на диске после завершения работы DEE.

#### 2.6 AudioSpeedScriptTests (Изменение скорости)
- [ ] Проверка пресетов PAL ↔ NTSC (изменение скорости `-24.000` в `23.976` и наоборот).
- [ ] Валидация CLI аргументов утилиты `eac3to` (флаги скорости `-24.000`, `+25.000`).
- [ ] Проверка коррекции высоты тона звука (pitch correction) при изменении скорости.
- [ ] Обработка неподдерживаемых форматов в eac3to через предварительное WAV-декодирование.

#### 2.7 AudioChannelsScriptTests (Разделение каналов)
- [ ] Проверка извлечения каждого канала из многоканального аудио (5.1/7.1) в отдельные моно-файлы.
- [ ] Валидация фильтра маппинга FFmpeg (аргументы `-map_channel`).
- [ ] Проверка генерации выходных имен файлов с суффиксами каналов (`_L`, `_R`, `_C`, `_LFE`, `_SL`, `_SR`).

#### 2.8 MkvAssemblyScriptTests (Сборка MKV)
- [ ] Проверка автопоиска сопутствующих аудиодорожек и субтитров по совпадению имен файлов.
- [ ] Валидация настройки позиционирования: вставка новых дорожек перед встроенными или после них.
- [ ] Тестирование сборки аргументов mkvmerge: флаги `--track-order`, `--language`, `--track-name`.
- [ ] Проверка обработки путей с пробелами и спецсимволами.

#### 2.9 StreamManagementScriptTests (Управление потоками)
- [ ] Проверка удаления выбранных аудио/видео/субтитров по индексам.
- [ ] Валидация CLI mkvmerge: генерация флагов `--audio-tracks`, `--video-tracks`, `--subtitle-tracks`.
- [ ] Проверка принудительного выставления флагов "по умолчанию" (`--default-track`) и "принудительно" (`--forced-display-flag`).

#### 2.10 StreamReplacementScriptTests (Замена потоков)
- [ ] Проверка подмены оригинальных дорожек внешними файлами с сохранением их оригинальных позиций.
- [ ] Валидация наследования метаданных: язык, имя, флаги заменяемого потока.
- [ ] Тестирование предотвращения утечки глав и тегов из исходных контейнеров.

#### 2.11 TrackExtractorScriptTests (Разборка контейнера)
- [ ] Проверка извлечения аудио, видео, субтитров и вложений (шрифтов) через mkvextract.
- [ ] Валидация CLI: аргументы `tracks` и `attachments`.
- [ ] Проверка автоматической генерации подпапок для каждого обрабатываемого файла.
- [ ] Тестирование автоконвертации субтитров Timed Text и WebVTT в ASS при извлечении.

#### 2.12 SubtitlesConvertScriptTests (Конвертация субтитров)
- [ ] Валидация фильтрации строк по стилям, актерам, эффектам.
- [ ] Проверка очистки тегов форматирования (FFmpeg-режим и локальный регулярный парсинг).
- [ ] Тестирование ручного исключения строк (пропуск выбранных чекбоксов).
- [ ] Проверка автосортировки реплик по времени и нормализации таймкодов.
- [ ] Устранение утечек памяти и зависаний на файлах субтитров размером > 10 МБ.
