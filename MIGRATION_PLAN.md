# План дальнейшей миграции скриптов KTools с Python на C#

Этот документ содержит пошаговый план переноса оставшихся 10 скриптов медиаобработки из Python-версии приложения в C#-версию KTools.App на основе уже внедренной архитектуры MVVM + DI.

---

## 1. Сравнение текущего состояния версий

| Функция / Модуль | Версия Python (app/) | Версия C# (src-csharp/KTools.App/) |
| :--- | :--- | :--- |
| **Архитектура** | PySide6, тесная связь UI и логики | WinUI 3, строгое разделение MVVM + DI |
| **Система зависимостей** | Загрузка и проверка утилит | Реализована полностью через DI-сервисы |
| **Очередь файлов** | Drag-and-Drop, анализ ffprobe | Реализована с асинхронной моделью через MediaProbeService |
| **Очистка метаданных** | Реализована (metadata_cleaner.py) | Реализована полностью (MetadataCleanupScript.cs) |
| **Извлечение дорожек** | Реализована (track_extractor.py) | Реализована полностью с интерактивным деревом (TrackExtractorScript.cs) |
| **Другие 10 скриптов** | Все реализованы и протестированы | Представлены в виде заглушек (Scripts/Stubs.cs) |

---

## 2. Предлагаемый план поэтапной миграции

Для минимизации рисков и поэтапной интеграции оставшиеся скрипты разбиты на 4 логические фазы по уровню сложности и зависимостям.

### Фаза 1: Простые скрипты конвертации (без сложных UI-виджетов)
Перенос скриптов, которые используют стандартный интерфейс параметров и не требуют интеграции с графическим деревом выбора дорожек.
*   **Скрипт «Конвертация контейнера»** (вместо ContainerConversionStub) — **В РАБОТЕ**:
    *   *Источник*: container_converter.py
    *   *Технология*: Вызов FFmpeg для быстрого копирования потоков (-c copy) в контейнеры MKV/MP4.
*   **Скрипт «ASS/SRT → VTT»** (вместо SubtitlesConvertStub):
    *   *Источник*: ass_to_vtt_converter.py
    *   *Технология*: Нативный C# парсер текстовых файлов субтитров с логикой фильтрации тегов оформления и реплик актеров. Не требует внешних CLI-зависимостей.

### Фаза 2: Аудио-скрипты (FFmpeg, qaac, eac3to, DEE)
Перенос скриптов обработки звука с интеграцией специализированных раннеров.
*   **Скрипт «Кодирование аудио»** (вместо AudioEncodingStub):
    *   *Источник*: audio_converter.py
    *   *Технология*: Кодирование через FFmpeg (AAC, FLAC, AC3, E-AC3) и внешнюю утилиту qaac (QaacRunner) для кодирования в Apple AAC.
*   **Скрипт «Даунмикс в Stereo»** (вместо AudioDownmixStub):
    *   *Источник*: audio_dee_downmixer.py
    *   *Технология*: Генерация XML-конфигурации и запуск Dolby Encoding Engine через DeeRunner для профессионального даунмикса.
*   **Скрипт «Изменение скорости аудио»** (вместо AudioSpeedStub):
    *   *Источник*: audio_speed_changer.py
    *   *Технология*: Использование Eac3toRunner для тайм-стретчинга аудиодорожек (PAL ↔ NTSC).
*   **Скрипт «Разделение каналов»** (вместо AudioChannelsStub):
    *   *Источник*: audio_splitter.py
    *   *Технология*: Демультиплексирование многоканального аудио в отдельные моно-WAV файлы через FFmpeg.

### Фаза 3: Сложные скрипты контейнеров (с интеграцией дерева выбора дорожек)
Интеграция скриптов, требующих детальной работы с конкретными дорожками медиафайлов, выбранными пользователем.
*   **Скрипт «Сборка MKV»** (вместо MkvAssemblyStub):
    *   *Источник*: muxer.py
    *   *Технология*: Сборка видео, аудио и субтитров в единый файл через MkvmergeRunner с сопоставлением по имени.
*   **Скрипт «Управление потоками»** (вместо StreamManagementStub):
    *   *Источник*: stream_manager.py
    *   *Технология*: Удаление нежелательных дорожек из MKV/MP4 файлов на основе выбранных в дереве элементов.
*   **Скрипт «Замена потоков»** (вместо StreamReplacementStub):
    *   *Источник*: stream_replacer.py
    *   *Технология*: Мультиплексирование внешних дорожек взамен существующих в исходном медиафайле.

### Фаза 4: Комплексная обработка видео
*   **Скрипт «Кодирование видео»** (вместо VideoEncodingStub):
    *   *Источник*: video_processor.py
    *   *Технология*: Самый объемный скрипт. Включает 10-битное кодирование x264/x265, расчет битрейта, аппаратное ускорение NVENC/QSV, обрезку кадров и вшивание субтитров.
