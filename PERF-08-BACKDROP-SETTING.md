# Блок 08: Настройка фона окна (Mica/Acrylic/Обычный)

## Цель

На слабом железе (типичная HDD-машина со слабым iGPU) убрать постоянную
стоимость блюра: пользователь может выбрать обычный фон, выбор применяется
без рестарта и запоминается.

## Контекст

`MainWindow.ApplySavedBackdrop()` (`MainWindow.xaml.cs:733-795`) ставит
`MicaBackdrop`/`DesktopAcrylicBackdrop`. Блюр на весь фрейм на старом железе
дает просадки скролла и анимаций — воспринимается как «тормоза» уже после
запуска. Механизм сообщений `BackdropChangedMessage` уже есть (подписка в
ctor `MainWindow`), не хватает только третьего состояния и UI.
Ключ настройки: `SettingsManager.BackdropType` (`General/BackdropType`,
значения `Mica`/`Acrylic`).

## Зона правок (владение блока)

- `KTools.App/MainWindow.xaml.cs` (методы `ApplySavedBackdrop`/`ApplyBackdrop`).
- `KTools.App/Services/Implementations/SettingsManager.cs` — только свойство
  `BackdropType` (дефолт и допустимые значения, валидация неизвестных).
- Экран настроек (XAML + VM): добавить вариант «Обычный» в существующий
  выбор фона.
- ЗАПРЕЩЕНО трогать: стартовый путь, `App.xaml.cs`, проверки зависимостей.

## Шаги

1. Добавить значение «Обычный» (`None`/`Solid` — имя на усмотрение исполнителя):
   `SystemBackdrop = null` +solid-фон, неизвестные старые значения маппятся
   на `Mica` (текущий дефолт).
2. Дефолт для новых установок: оставить `Mica` (не менять поведение молча);
   опционально — авто-дефолт «Обычный» при слабом GPU обсуждается отдельно,
   в этом блоке не делать.
3. Переключение применять мгновенно через существующий
   `BackdropChangedMessage`, без рестарта; выбор персистится как остальные
   настройки.
4. Логи `window.backdrop_applied/failed` сохранить, добавить значение в свойства.

## Инварианты

- Тема (`Theme`) и фон (`BackdropType`) независимы; смена одного не сбрасывает
  другое.
- `x:Bind` с явным `Mode`, верстка по RULES §2 (карточки/экспандеры).

## Приемка

- Переключение Mica → Обычный на слабом iGPU убирает просадки (субъективно +
  FPS скролла), после рестарта выбор на месте, неизвестное значение из
  старого конфига не роняет окно.

## Проверка

- `dotnet build KTools.sln -c Debug -p:Platform=x64`
- `dotnet test KTools.sln -c Debug -p:Platform=x64` + тесты VM/маппинга
  значения фона.
