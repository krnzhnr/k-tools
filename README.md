# K-Tools

**K-Tools (v2.0.0)** — настольное Windows-приложение для пакетной обработки, транскодирования, ремуксинга медиафайлов и работы с метаданными. Построено на C#, .NET 10 и WinUI 3.

Приложение предоставляет графический интерфейс над консольными утилитными бинарниками (FFmpeg, mkvmerge, eac3to, QAAC, DEE, yt-dlp), изолированными от системного `PATH`.

---

## 🛠️ Технологический стек

* **Фреймворк**: .NET 10.0 (Windows 10/11 x64)
* **Пользовательский интерфейс**: WinUI 3 / Windows App SDK 2.1 (Fluent Design, Mica/Acrylic)
* **Архитектура**: MVVM (`CommunityToolkit.Mvvm`), Dependency Injection (`Microsoft.Extensions.DependencyInjection`)
* **Тестирование**: MSTest + Moq (`KTools.App.Tests`, 100 юнит-тестов)
* **Сборка и упаковка**: Inno Setup 6 + Python-скрипт автоматизации (`build_csharp.py`)
* **Встроенные бинарники**: `kt-ffmpeg`, `kt-ffprobe`, `mkvmerge`, `mkvpropedit`, `eac3to`, `qaac64`, `yt-dlp`, `DEE`

---

## 📂 Модули и функциональность

### 🎞️ Видео и Контейнеры
* **Кодирование видео**: Транскодирование видеорядовых потоков с поддержкой аппаратного ускорения (NVIDIA NVENC, CUVID), программных кодеков (x264, x265, AV1), вшиванием субтитров и настройкой звука.
* **Конвертация контейнера**: Перемещение видео/аудио потоков в другой контейнер (MKV <-> MP4) без перекодирования (`-c copy`).
* **Очистка метаданных**: Удаление глобальных тегов, служебных заголовков и названий дорожек (`-map_metadata -1`).

### 🎵 Аудио инструменты
* **Кодирование аудио**: Перекодирование аудио в 15+ форматов (QAAC Apple AAC, FLAC, WAV, AC3, EAC3, OPUS, MP3, DTS) с настройкой битрейта и профилей качества.
* **Даунмикс в Stereo**: Понижение канальности 5.1/7.1 в Stereo 2.0 (DDP/DD) через Dolby Encoding Engine (DEE) или FFmpeg.
* **Пересадка аудио**: Инструмент сведения аудиодорожек с графическим интерфейсом нативной отрисовки осциллограмм на GPU (Win2D) и компенсацией задержки кодирования.
* **Разделение каналов**: Разделение многоканального аудио на отдельные моно-WAV файлы с поддержкой автоматической объединяющей склейки через `eac3to`.
* **Изменение скорости аудио**: Коррекция скорости/тона аудиопотока (PAL 25.0 fps <-> NTSC 23.976 fps) с помощью `eac3to`.
* **Сдвиг аудио**: Изменение временного сдвига (задержки) аудиопотока с сохранением в Lossless-форматы (FLAC/WAV).

### 📝 Работа с субтитрами
* **Конвертация субтитров**: Преобразование ASS/SSA/SRT в WebVTT с фильтрацией по актерам/стилям, Regex-очисткой тегов и живым предпросмотром.
* **Сдвиг субтитров**: Изменение тайминга субтитров (ASS, SRT, VTT, SSA) на заданное количество миллисекунд.
* **Калькулятор таймингов**: Расчет коррекции сдвига субтитров по ключевым точкам кадра в стиле Aegisub.

### 🏗️ Сборка, Извлечение и Сеть
* **Сборка MKV**: Автоматическое сопоставление одноименных файлов в папке и объединение видео, аудио и субтитров в единый мастер-файл через `mkvmerge`.
* **Управление потоками**: Исключение или сохранение выбранных дорожек (видео, аудио, субтитры) в MKV и MP4 файлах без перекодирования.
* **Замена потоков**: Замена конкретных дорожек в существующем файле на внешние элементы с сохранением остальных компонентов.
* **Разборка контейнера**: Массовое извлечение потоков из MKV/MP4 с категоризацией (Видео, Аудио, Субтитры) и авто-именованием по шаблонам.
* **Загрузка медиа**: Скачивание видео/аудио по ссылке через `yt-dlp` с выбором качества, битрейта и фоновым обновлением утилиты.

## ⚙️ Архитектурные особенности

1. **Изоляция бинарников (`IPathManager`)**: Все дочерние утилиты вызываются только из рабочей папки `bin/` по их именам (`kt-ffmpeg.exe`, `kt-ffprobe.exe`, `mkvmerge.exe`), предотвращая обращение к системному `PATH`.
2. **Контроль дочерних процессов (`ActiveProcessTracker`)**: Все консольные процессы регистрируются во время выполнения и принудительно завершаются при закрытии приложения.
3. **Асинхронность и CancellationToken**: Все долгие операции выполняются асинхронно с поддержкой мгновенной отмены и обратной связью через `IProgress<T>`.
4. **Локализация и логирование**: Ведение подробных журналов на русском языке с ротацией лог-файлов и фоллбеком при критических ошибках.
5. **Сброс фокуса (`FocusHelper`)**: Глобальное снятие фокуса с текстовых полей по нажатию клавиши `Enter` или клику по пустой области окна (Issue #19).

## 🚀 Сборка из исходного кода

### Требования
* Visual Studio 2022 / .NET 10.0 SDK
* Python 3.12+
* Inno Setup 6+ (для сборки `.exe` инсталлятора)

### Инструкция по сборке

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/krnzhnr/k-tools.git
   cd k-tools
   ```

2. Скомпилировать решение в Debug:
   ```bash
   dotnet build KTools.sln -c Debug -p:Platform=x64
   ```

3. Запустить юнит-тесты:
   ```bash
   dotnet test KTools.App.Tests/KTools.App.Tests.csproj -c Debug -p:Platform=x64
   ```

4. Собрать релизный инсталлятор:
   ```bash
   python build_csharp.py
   ```
   Готовый установочный файл будет создан в папке `setup_output/`.
