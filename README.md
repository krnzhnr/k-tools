# K-Tools

**K-Tools (v2.0.0)** — настольное Windows-приложение для пакетной обработки, транскодирования, ремуксинга медиафайлов и работы с метаданными. Построено на C#, .NET 10 и WinUI 3.

Приложение предоставляет графический интерфейс над консольными утилитными бинарниками (FFmpeg, mkvmerge, eac3to, QAAC, DEE, yt-dlp), изолированными от системного `PATH`.

---

## 🛠️ Технологический стек

* **Фреймворк**: .NET 10.0 (Windows 10/11 x64)
* **Пользовательский интерфейс**: WinUI 3 / Windows App SDK 2.1 (Fluent Design, Mica/Acrylic)
* **Архитектура**: MVVM (`CommunityToolkit.Mvvm`), Dependency Injection (`Microsoft.Extensions.DependencyInjection`)
* **Тестирование**: MSTest + Moq (`KTools.App.Tests`, 100 юнит-тестов)
* **Сборка и упаковка**: Inno Setup 6 + Python-скрипт автоматизации (`build_csharp.py`)
* **Встроенные бинарники**: `kt-ffmpeg`, `kt-ffprobe`, `mkvmerge`, `mkvpropedit`, `eac3to`, `qaac64`, `yt-dlp`, `DEE`

## 📂 Модули и функциональность

### 🎞️ Видео и Контейнеры
* **Ремуксинг (Container Conversion)**: Быстрое изменение контейнера (MKV <-> MP4) без перекодирования потоков (`-c copy`).
* **Кодирование видео (Video Encoding)**: Транскодирование видеорядовых потоков с поддержкой аппаратного ускорения (NVIDIA NVENC, CUVID) и программных кодеков (x264, x265, AV1).
* **Очистка метаданных (Metadata Cleanup)**: Удаление глобальных тегов, служебных заголовков и названий дорожек (`-map_metadata -1`).

### 🎵 Аудио инструменты
* **Транскодирование аудио (Audio Encoding)**: Конвертация аудио в 15+ форматов (QAAC Apple AAC, FLAC, WAV, AC3, EAC3, OPUS, MP3, DTS) с точной настройкой битрейта и профилей.
* **Пересадка аудио (DubSwap)**: Визуальный инструмент сведения и подгонки дорожек с аппаратной отрисовкой осциллограмм на GPU и компенсацией AAC-задержки.
* **Даунмикс (Audio Downmix)**: Понижение канальности многоканального звука (5.1/7.1 -> 2.0 Stereo) с использованием Dolby Encoding Engine (DEE) или FFmpeg.
* **Разделение каналов (Audio Channels)**: Поканальное демультиплексирование многоканальных треков на моно-WAV файлы через `eac3to`.
* **Сдвиг аудио (Audio Shift / Speed)**: Изменение темпа и времени задержки аудиопотоков без изменения питча (PAL 25.0 fps <-> NTSC 23.976 fps).

### 📝 Работа с субтитрами
* **Сдвиг субтитров (Subtitle Shift)**: Пакетный сдвиг временных меток субтитров (ASS, SRT, VTT).
* **Калькулятор таймингов (Timing Calculator)**: Расчет коррекции сдвига по ключевым точкам кадра в стиле Aegisub.
* **Конвертация субтитров (Subtitles Convert)**: Преобразование ASS/SSA в WebVTT с последовательной Regex-фильтрацией тегов, фильтрацией по актерам/стилям и предпросмотром.

### 🏗️ Муксинг, Извлечение и Сеть
* **Сборка MKV (MkvAssembly)**: Автоматическое сопоставление одноименных файлов и объединение видео, аудио и субтитров в единый файл через `mkvmerge`.
* **Извлечение дорожек (Track Extractor)**: Массовое извлечение выбранных потоков с интерактивным деревом выбора, фильтрацией и шаблонизатором выходных имен.
* **Замена потоков (Stream Replacement)**: Точечная замена конкретных дорожек в контейнере на внешние ресурсы.
* **Загрузка медиа (Media Downloader)**: Скачивание видео/аудио по ссылкам через `yt-dlp` с выбором качества, формата и автообновлением зависимости.

## ⚙️ Архитектурные особенности

1. **Изоляция бинарников (`IPathManager`)**: Все дочерние утилиты вызываются только из рабочей папки `bin/` по их именам (`kt-ffmpeg.exe`, `kt-ffprobe.exe`, `mkvmerge.exe`), предотвращая обращение к системному `PATH`.
2. **Контроль дочерних процессов (`ActiveProcessTracker`)**: Все консольные процессы регистрируются во время выполнения и принудительно завершаются при закрытии приложения.
3. **Асинхронность и CancellationToken**: Все долгие операции выполняются асинхронно с поддержкой мгновенной отмены и обратной связью через `IProgress<T>`.
4. **Локализация и логирование**: Ведение подробных журналов на русском языке с ротацией лог-файлов и фоллбеком при критических ошибках.
5. **Сброс фокуса (`FocusHelper`)**: Глобальное снятие фокуса с текстовых полей по нажатию клавиши `Enter` или клику по пустой области окна.

## 🚀 Сборка из исходного кода

### Требования
* Visual Studio 2022 / .NET 10.0 SDK
* Python 3.12+
* Inno Setup 6+ (для сборки `.exe` инсталлятора)

### Инструкция по сборке

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/krnzhnr/k-tools.git
   cd k-tools
   ```

2. Скомпилировать решение в Debug:
   ```bash
   dotnet build KTools.sln -c Debug -p:Platform=x64
   ```

3. Запустить юнит-тесты:
   ```bash
   dotnet test KTools.App.Tests/KTools.App.Tests.csproj -c Debug -p:Platform=x64
   ```

4. Собрать релизный инсталлятор:
   ```bash
   python build_csharp.py
   ```
   Готовый установочный файл будет создан в папке `setup_output/`.
